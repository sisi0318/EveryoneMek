# Changelog

## 0.1.1

- 修复灵气发生器在剩余容量不足一整批产量时提前暂停的问题；现在可填满剩余空间，少量输出后即可恢复生产。
- 自然祭坛支持直接使用环境灵气；优先使用罐内灵气，仅从环境扣除不足部分，界面显示周围灵气。
- 将森林仪式机的树苗、金叶粉槽设为 Mek 的“额外”输入，独立于普通配方输入。
- 新增限装一个的金叶无限模块，在升级窗口中安装或取回，也支持潜行右键安装。免除专用槽金叶粉消耗，默认总耗电翻倍。
- 保持已有机器库存槽位编号，保存及拆卸机器时保留新模块。
- 补齐四台机器 `container.*` 界面标题的中英文翻译。
- 增加高速满罐边缘、侧面输入分离、模块行为和翻译回归测试。

## 0.1.0

- 初始四台机器：通用灵气发生器、通用森林仪式、通用自然祭坛、通用呼唤仪式。
