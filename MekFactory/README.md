# MekFactory · 并行矩阵工厂

**设计阶段，尚无可运行模组或 JAR。**

目标是将 Mek 的单方块加工机器接入可扩建工厂：主控安装机器与升级，框架决定规模和并行，端口扩展物料缓存，感应元件与供应器承担储能和吞吐。成型后可从任意外壳部件打开同一个界面。

当前方案、初拟数值、兼容范围和数据保存规则见 [DESIGN.md](DESIGN.md)。

当前按一台主机器决定加工类型、框架提供并行设计；机器投入数量仍是待用户选择的参数。设计参考现有项目实际使用的 Minecraft 1.21.1、NeoForge 21.1.241、Mekanism 10.7.19.85 发布依赖，不把开发分支契约当作已验证兼容。
