## 本轮设计

- [整机剖视概念](source/concept-v1.png)：内置 image_gen 原创生成。浅灰机壳、深色工作区、玻璃观察面，核心只保留一圈细紫光。图中省略前玻璃和部分顶盖，实际结构必须封闭；图像中的尺度与发射器造型只作外观参考。
- [七层总图](layers.svg)：以 [layout.json](layout.json) 为唯一位置数据，按 7×7×7 自动绘制。七层分别放置 49/25/24/29/24/25/49 个方块，共 225 个；内腔保留 118 格空气。
- [主控界面](main-ui.svg)：230×244 逻辑像素，净发电、实际输出、稳定度集中在原生风格信息区；钠/热钠使用储罐仪表，运行余量使用单条进度条，电缓存使用右侧细条。资源详细数字放悬停或侧栏，不重复增加一整排储量文本。
- [燃料仓界面](fuel-ui.svg)：176×208 逻辑像素，两行共 18 个燃料槽，直接接收固体燃料；不在主控重复摆放可取出的燃料库存。
- 主控看板提供运行、缺冷却、输出受限和停机四种演示状态。负载按钮以 25% 为步长切换，启动/停机可预览显示变化；能量、冷却、结构、红石和权限侧栏可展开。数值只演示信息关系，不是发电或热力学模拟。

第 2 层集中接口：正面左为燃料仓，中间主控，右为励磁输入；左侧为完整玻璃观察窗；背面四个发电口。此布局预留终极负载的出口，不要求初级运行时四口都接上线缆。

主控正面定义为 Z=0；X 从左向右，Y 从下向上，Z 从前向后。规范数据使用 0～6，玩家分层图使用第 1～7 层。核心位于 (3,3,3)，线圈位于六个轴向的距离 2 位置，均面向核心，中间一格留空。

棱角框架保留，中间面板允许接口替换。顶部和底部中间面板封闭，不能将概念剖视图省略的方块当成可留空位置。更多端口位置属于后续结构规则，默认搭建图只定义一套明确方案。

## 资源与复现

- 概念图使用内置 image_gen，完整提示词、参考说明和输出路径见 [concept-prompt.txt](concept-prompt.txt)。没有改用 API/CLI 或脚本重绘生成图。
- 参考现有 `MekFactory/art/reference/mekanism-textures.png` 和原创 `MekFactory/art/block-preview.png` 的配色与块面尺度；参考 Mek 发布件的 `GuiFusionReactorController`、`GuiSPS` 控件组织。没有复制原模组贴图或字体到本目录。
- `generate_design.py` 从 `layout.json` 和 `board.template.html` 生成 SVG 与看板；更改位置时编辑数据再运行，不单独改生成文件。
- 执行 `python docs/gravity-reactor/generate_design.py`。使用 Python 标准库，检查方块无重位、总数正确、六线圈朝向正确且隔一格，以及所有七个外壳设备朝向外侧。
- 已在浏览器检查分层选择、线圈详情、主控侧栏和燃料仓展示；不等于游戏内验收。没有运行 Minecraft 客户端、编译模组或提升模组版本。

功率、燃料、冷却和实现范围继续见 [机制提案](../MEK_GRAVITY_REACTOR_DESIGN.md)。
