# 更新日志

## 0.3.1

2026-09-10

- 德格米收获站、风转草培育站的合成材料改为原子合金与终极控制电路。

## 0.3.0

2026-09-10

- 德格米收获站新增 8 个机内收容罐槽，接入 FE 与管道魔源即可生产，无需外接石阵或绑定德格米。
- 保留原版的生物种类与数量奖励、掉落表、禁用名单及经验宝石换算；收容罐及生物数据不消耗、不修改。
- 默认每轮 10 秒，速度升级直接加快生产；每轮魔源成本仍遵循 Ars 配置。
- 保存每轮抽取结果，堵塞或重载不会重抽；较多产物分批输出，每轮只扣一次魔源，暂存产物随拆装保留。
- 新槽追加在原能量槽后，旧库存、升级、六面配置和筛选设置保持不变，原外接石阵方式继续可用。

## 0.2.2

2026-09-10

- 配方选择改为图标与名称列表，支持搜索；魔符可按等级筛选并查看经验、材料要求，未选择时不会自动制作。
- 移除配方 ID 输入框和“中央”等多余标签，中英文操作、状态与物品说明改用玩家用语；药水数量显示为瓶。
- 修复德格米等控制器已有原装置魔源供给时仍误报魔源不足；收集不再要求机内有管道魔源或顶部有罐。
- 仪式控制器接受火盆注册的各种石板，包括荒野召唤；增幅槽支持各仪式材料，新增手动启动以便依次装填多种增幅。
- 增幅槽移至石板下方，原槽位顺序、库存与骨块增幅模式保留。
- 德格米收获站、风转草培育站的合成中心改为对应符咒。

## 0.2.1

2026-09-10

- 通用魔源发生器合成配方的中心材料改为 FE 魔源通道。

## 0.2.0

2026-09-10

- 补齐通用魔源萃取机、通用魔法粉碎机、通用魔符抄写机、通用药水混合器、通用药水灌装机。
- 萃取保留食物、燃料容器，余热可加工岩浆块和熔岩桶；粉碎在完成时结算随机产物。
- 抄写保留法术书等级与魔符启用限制，消耗真实经验点，支持玩家存入与经验宝石物流输入。
- 药水机连接原生药水罐，保留完整效果，支持混合、药瓶与烧瓶装填和回收、药水箭灌装。
- 新增通用德格米收获站、通用风转草培育站和通用仪式控制器，保留真实生物、植物环境与原生仪式；仪式首批支持收获、繁育和过度生长。
- 生物产物通过受前面配置与筛选控制的收集接口进入缓存，再由 Mek 输出至箱子；原生进度与环境信息显示在界面中。
- 粉碎和抄写接入 Ars 原生 JEI 分类；新增八套灰黑与紫色 16×16 方块贴图。原有机器 ID、槽位和数值不变。

## 0.1.2

2026-09-10

- 新增 FE 魔源通道，沿用 Ars 原生通道外观，接电后为正上方或正下方的魔源罐生成魔源。
- 通道支持真实 FE 电缆供电、缺罐或满罐停机、按实际产量耗电、储能状态显示与拆装保存。
- 四台工业机器统一命名为通用魔源发生器、通用魔源转换器、通用魔源灌注室、通用魔源附魔装置；已有注册 ID 不变。

## 0.1.1

2026-09-10

- 灌注和附魔机器接入 Ars 原生 JEI 分类，沿用环形配方展示，移除重复的工业配方分类。
- 显示名调整为魔源发生器、魔源转换器、魔源灌注室、魔源附魔装置；注册 ID 不变，原有机器与库存可继续使用。
- 去除“催化物（保留）”等界面解释性文字，缩短物品提示；产率和转移上限显示升级后的有效数值。

## 0.1.0

2026-09-10

- 新增通用魔源发生器、魔源转换器、通用灌注室和通用附魔装置。
- 魔源以 1:1 比例在 Mek 管网与相邻 Ars 容器之间双向转换，按实际转移量耗电。
- 灌注保留催化物；普通合成支持堆叠材料、组件继承、保留材料与容器返还；装备附魔遵循原版逐级和兼容规则。
- 接入 Mek 六面配置、自动输出、速度/能量升级、红石控制、安全设置和拆装保存。
- 新增配方锁定、JEI 三类配方、中文与英文文本，以及灰黑机壳搭配紫色功能部件的 16×16 贴图。
- 开发依赖：Minecraft 1.21.1、Java 21、NeoForge 21.1.241、Mekanism 10.7.19.85、Ars Nouveau 5.13.1、GeckoLib 4.6.6、Curios 9.3.1；配方查看使用 JEI 19.22.1.316，手册使用 Patchouli 1.21-87。

客户端界面与游戏内材质验收由玩家完成。
