# Ars Mekanism

把 Ars Nouveau 的魔源、灌注和附魔接入 Mekanism 产线，适用于 Minecraft 1.21.1 / NeoForge。客户端与服务端都需安装本模组、Ars Nouveau、Mekanism，以及 Ars 要求的依赖；JEI 为可选配方查看器。验证过的依赖组合见 [CHANGELOG](CHANGELOG.md)，安装时按该组合选择加载器和依赖版本。

## 机器与接线

| 机器 | 使用方法 |
| --- | --- |
| 通用魔源发生器 | 以 FE 魔源通道为中心材料合成。输入 FE 产生魔源，用 Mek 加压管道输出到化学品储罐或加工机器。 |
| 通用魔源转换器 | 紧贴魔源罐，选择「连接方向」；用「向魔源设备输送」填罐，或用「从魔源设备抽取」将魔源送入管道，两种方向都耗电。 |
| 通用魔源灌注室 | 中央放原料，左侧放催化物，输入 FE 和魔源。每次消耗一个中央原料，催化物保留。 |
| 通用魔源附魔装置 | 中央放原料、书或装备，左侧放配方材料，输入 FE 和魔源；选择「物品合成」或「装备附魔」。普通材料消耗，法术羊皮纸等保留材料不消耗，空桶等容器进入产物槽。 |
| FE 魔源通道 | 任意面接入 FE，紧贴正上方或正下方放 Ars 魔源罐；生成的魔源直接进入罐内。 |
| 通用魔源萃取机 | 中央放食物或燃料，选择对应模式，输入 FE 并用加压管道输出魔源。燃料会积累余热，可切换「余热加工」处理左侧材料。 |
| 通用魔法粉碎机 | 放入原料并接电，按粉碎配方生成产物；可点击「选择配方」指定产物。 |
| 通用魔符抄写机 | 点击「选择魔符」，按名称搜索或等级筛选，点击目标后放入相应等级的法术书、材料和经验并接电。 |
| 通用药水混合器 | 左右紧贴两个输入药水罐，上方紧贴输出药水罐，输入 FE 与魔源。 |
| 通用药水灌装机 | 前方紧贴药水罐，中央放药瓶、烧瓶或箭，接电后选择「灌装容器」或「回收药液」。 |
| 通用德格米收获站 | 合成需原子合金和终极控制电路，中心为德格米符咒。左上放入最多 8 个装有生物的收容罐，接入 FE 和管道魔源即可生产掉落物；速度升级加快生产。 |
| 通用风转草培育站 | 合成需原子合金和终极控制电路，中心为风转草符咒。前方紧贴已绑定风转草的花，接电并保留周围植物环境。花可使用附近已有魔源罐。 |
| 通用仪式控制器 | 前方紧贴仪式火盆，放入石板并接电；石板下方一格放增幅材料。接受火盆注册的各种仪式，包括荒野召唤。 |

1 单位管道魔源等于 1 点 Ars 魔源。它是机器资源，不是玩家施法用的魔力。需要让原版 Ars 设备使用电力产生的魔源时，可按下面连接：

```text
FE → 通用魔源发生器 → 加压管道 → 通用魔源转换器 → 相邻 Ars 魔源罐
                          └→ 通用魔源灌注室 / 通用魔源附魔装置
```

通用机器均支持 Mek 速度、能量升级、红石控制与安全设置。配方魔源在完成时扣除，电力在加工时持续消耗；缺电、缺魔源或产物槽满时暂停。发生器和转换器按实际产生、转移的数量结算电力。德格米收获站的机内生产周期直接受速度升级影响；外接生物和仪式仍按 Ars 的规则运行。

FE 魔源通道沿用 Ars 原生魔源通道外观，可单独搭成下面的供魔结构。罐也可以放在通道正下方，上下不能隔开；两侧都有罐时优先上方，上方满后供给下方。没有可用魔源罐、罐满或缺电时停止生产，剩余空间不足一批时按实际产量耗电。空手右键或看向通道可查看储能与状态。

```text
    Ars 魔源罐
        │
  FE 魔源通道 ← 电缆 ← FE 电源
```

通道使用发生器的基础产率与耗电配置，无升级槽或机器界面；罐中的魔源可以直接供原版 Ars 设备使用。

## 萃取、抄写与药水

萃取机保留食物的碗、瓶及燃料容器。余热加工时，左侧第一格放石头或岩浆块，第二格放空桶：石头消耗 150 点余热变成岩浆块；岩浆块与空桶消耗 200 点余热变成熔岩桶。余热满后燃料模式暂停，食物模式仍可工作。余热随机器保存和拆装保留。

粉碎机在开工前为全部可能产物预留空间，完成时进行一次随机结算。它与抄写机、灌装机只需 FE，不接收魔源。

抄写机必须先选择魔符；列表显示魔符图标、名称、等级和经验消耗，鼠标悬停可查看材料。法术书保留，材料和经验点在完成时扣除。法术书等级不足或魔符被禁用时不能制作。点击「存入经验」每次最多存入 100 点；也可把 Ars 经验宝石送入右侧 XP 槽，上方物品面默认为「输入 2」。未消费经验随世界和拆机物品保存，制成魔符后仍需玩家使用才能学习。

药水混合器按 Ars 配置消耗左右两罐的药液与魔源，生成对应数量的混合药液。重复效果、效果相同的两路药液或不兼容的输出罐会阻止加工。药水罐的位置按机器朝向判断，左右罐不能用同一罐替代。

灌装机每瓶药水使用 100 单位药液，每支药水箭使用 10 单位。Ars 烧瓶一次补满或全部回收，每份容量对应 100 单位；药效不同的非空烧瓶不能混装。药瓶和烧瓶可回收，药水箭不能回收。药水保留效果、等级、持续时间与自定义效果；成品通过物品物流运输。

## 生物与仪式控制器

德格米收获站可直接在机器内使用收容罐，不需要外接石阵或绑定德格米。八个罐槽每格放一罐，罐子与其中的生物均保留；顶部「输入 2」可自动送入装有生物的罐子，取出罐子需手动操作。旧机器会保留原六面设置，需要管道送罐时将对应物品面设为「输入 2」。

机内生产沿用原版的种类奖励、数量奖励、掉落表、禁用生物和经验宝石换算。相同种类的多个罐会增加数量，不会重复计算种类奖励。默认每轮 10 秒、消耗 1,000 点魔源；速度升级缩短周期，单轮魔源消耗保持不变，电耗按 Mek 升级规则调整。界面显示生物数、种类数、奖励和实际周期。

产物从右侧输出。一次收获超过输出槽容量时，剩余物品会暂存并优先分批输出，界面显示「待输出」数量；暂存物品随世界保存与拆机物品保留，取出收容罐后仍会继续输出。筛选只保留符合条件的产物，被筛掉的结果不会换成其他掉落物。

没有机内收容罐时，德格米收获站仍可沿用旧的外接石阵方式，旧库存与设置不会清空。三台控制器外接原装置时，都可使用原装置附近已有的魔源供给，机内没有管道魔源也能收集。需要由控制器主动供魔时，在上方紧贴魔源罐，再接入管道魔源，接法如下。前方是控制器的正面，产物先进入收集区，再经输出面进入箱子或物流管道。

```text
               魔源罐
                  │
FE、管道魔源 → 控制器 → 右侧箱子
                  │ 正前方
          石阵／风转草之花／仪式火盆
```

外接德格米石阵仍需周围生物或摆放的收容罐，风转草仍需周围植物。控制器显示石阵的奖励或花的环境评分。筛选槽可放一个样品，选择允许或排除；空槽接收全部产物。筛选会区分附魔等物品数据，样品保留。关闭前方物品输入面也会阻止原装置向收集区投放。

仪式控制器按火盆规则接收石板与增幅，保留各仪式的消耗、环境要求和效果。「自动启动」先添加增幅槽里可用的材料，条件满足后启动。需要依次加入多种增幅时，先切换「手动启动」，将材料依次放进石板下方的增幅槽，装填完成后点击「启动」。例如荒野召唤可按原火盆规则加入尖刺、角和膜翼；目标、方位等材料上的信息会一并保留。未满足条件时继续等待，也可直接在原火盆上添加材料、启动。

「骨块增幅」保留用于过度生长的动物催熟效果，会等待骨块后启动。左侧七格收集产物，物品「额外」面供给石板与增幅材料。持续运行的仪式不会被下一张石板覆盖，原仪式结束后才装填下一张。控制器支持火盆注册的仪式，附加模组的特殊条件仍由该仪式决定。

红石暂停或断电会停止控制器的供给、收集与启动；已经启动的原装置可继续使用魔源罐中的存量。控制器不取消正在运行的仪式，也不替代原装置的停用操作。

## 六面配置与自动化

加工机器默认背面输入中央物品，其余普通输入面供给左侧材料，右侧输出产物，底面物品口接收充能物品。可在物品六面配置中选择「额外」输入中央物品，选择「输入」供给左侧材料；只有一个原料槽的粉碎机和灌装机也可通过普通输入面供料。输出口自动弹出到箱子或物流管道，保留的催化物、法术书和筛选样品不会被输出管道抽走。

能量可从任意开启的能量输入面接入。加工机器的化学品输入仅接收本模组的魔源；发生器输出魔源。

转换器的「连接方向」专门连接相邻魔源设备。切换输送／抽取时，其余化学品面同步改为输入／输出；更改连接方向时，原方向恢复当前模式的管道设置。可再在六面配置中关闭不需要的管道面。「停止传输」停止与相邻设备交换，缓冲罐仍可从开启的管道输入面存入魔源。

## 配方与锁定

灌注、附魔、粉碎、抄写机器接入 Ars 原有 JEI 分类，沿用原生配方展示。查看机器用途时会打开对应的原生配方页。相同材料可以堆叠在同一个材料槽中，数量仍须满足全部要求。

点击「选择配方」或「选择魔符」打开列表，用名称搜索后点击目标即可。条目显示产物图标与名称，附魔条目显示具体附魔和等级；悬停查看原料与消耗。下方显示当前选择。灌注、附魔和粉碎可在列表中选「自动匹配」，切换附魔装置模式也会恢复自动匹配；抄写机取消选择后会等待重新选择魔符。

装备附魔遵循原配方的适用物品、附魔冲突和逐级提升规则。JEI 用书演示等级变化，也可放入兼容装备。物品合成按配方规定保留附魔等数据并处理耐久。

灌注与附魔装置支持普通灌注、普通附魔装置合成与普通装备附魔，包括使用这些类型的数据包配方。护甲能力升级、反应附魔、法术抄入和第三方自定义配方类型需另行适配。灌注、附魔、抄写的材料区均有八个槽位。

## 保存与配置

拆下通用机器后保留库存、魔源、电力、升级、六面配置及模式、已选配方等设置。重新放置后从头加工；世界保存与重载保留未完成进度。更换原料、催化物、物品上的附魔等数据或目标配方会重置加工进度，尚未完成时不会扣除材料与配方魔源。FE 魔源通道拆装与世界重载均保留储能。

服务端配置位于世界的 `serverconfig/arsmekanism-server.toml`，可调整发生器产率、转换速率、各机耗电和加工时间。德格米机内基础周期使用 `drygmy_station.harvestTicks`，默认 200 tick；旧的 `operationTicks` 继续控制外接供给和收集。默认值与范围由 [MachineConfig](src/main/java/dev/everyonemek/ars/MachineConfig.java) 定义；配方魔源成本来自配方本身，药水混合用量与生物生产消耗遵循 Ars 配置。

美术预览与导出方法见 [art](art/README.md)，后续机器构想见 [设计提案](DESIGN.md)。开发与服务端测试入口见 [AGENTS](AGENTS.md)。
