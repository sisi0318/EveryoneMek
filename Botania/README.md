# Botania × Mekanism（设计中）

目标是为 Botania 提供专用仿生花的 FE 魔力供给、Mek 物流加工和仿生功能花。

用户指定适配 **Minecraft 1.21.1／NeoForge** 的 Botania `1.21.1-porting` 分支。当前只有设计文档，尚无可安装 JAR。

- [完整设计方案](DESIGN.md)：资源互通、机器、仿生花、进度与分阶段验收。
- [魔力无线网络](WIRELESS.md)：共鸣花核心、收发／中继节点、距离、带宽、费用和权限。
- [上游核对记录](UPSTREAM.md)：固定源码版本、配方覆盖和实现契约。
- [开发入口](AGENTS.md)：已确认要求与下一步。

已确定用一款专用仿生花接 FE 产魔力，取消机器式魔力发生器。专用花暂名“仿生导能莲”，采用可带科技细节的原创花形，经原发射器和魔力池供给生产线。

另外建议六种仿生功能花：翡翠苋、粘土花、田园康乃馨、漏斗花、手掌花和冶炼火，保留各自原模型。**全部仿生花不要求草地或泥土，可安装在普通承托方块或供电部件上。**

导能莲平衡初稿为每株 200 FE／tick 产生 4 魔力／tick，首版无速度升级；更多产能依靠花阵列与发射器。具体数值、合成门槛和验收条件见设计提案，尚未通过实测。

无线网络暂按同维度基地方案设计：共鸣花管理，共鸣芽收发或中继；单链路建议 32 格，全网 128 魔力／tick。源池保留量、接收目标量和优先级可设定；魔力始终存在实际池或机器中，区块卸载后暂停，详细费用与范围见无线方案。
