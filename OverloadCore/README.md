# Overload Core · 过载短路核心

**设计阶段，尚无可安装版本。** 面向 Minecraft 1.21.1／NeoForge 科技整合包，以 Mekanism 为首要适配对象的诅咒饰品模组。

装备过载短路核心后，玩家需要承受更高的电力成本、供能与物流瓶颈，以及近距离作业风险；作为回报，部分生产配方增产，并获得随身电能回收和机具辅助能力。

用户已确认：设备效果随佩戴者移动，范围为同维度 32 格，只作用于自己或明确共享的设备。
