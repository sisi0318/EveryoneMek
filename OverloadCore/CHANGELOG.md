# 变更记录

## 0.1.0-alpha.23 · 2026-09-30

- 远程形态改为仅消耗原生电量，取消铁粒装填、扣弹、弹仓HUD和提示。
- 原弹仓模块改为磁轨复位单元，保留已装等级，每级缩短2 tick发射恢复时间，最低2 tick。
- 近战工具头改为弧形接触刃；斩击改为较窄刃沿、短残影和细电弧，减少整片月牙填充。
- 大面积能量面使用普通透明混合，火花单独加色；远程加入分段聚焦环、脉冲电磁环与命中扩散环，控制白光范围。
- 50项服务端测试通过，验证无需弹药、铁粒不变、真实耗电和复位效果；实际GLSL检查暗背景、射手视角和5阶段亮天空输出。未启动客户端。
