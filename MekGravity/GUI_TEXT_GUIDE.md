# MekGravity 界面与文本约定

本轮依据实际发布件核对，不以旧教程或概念图代替当前 GUI 契约。客户端游戏内观感仍由用户验收。

## 参照对象

| 发布件 | 核对内容 | 采用的做法 |
| --- | --- | --- |
| Mekanism 1.21.1-10.7.19.85 | `assets/mekanism/lang/{zh_cn,en_us}.json`；`GuiFrequencySelector`、`GuiConfirmationDialog`、`GuiTextField` | 频率列表、公私有分类、设置／删除、输入名称后回车、删除确认；确认数值与输入框分开 |
| Mekanism Generators 1.21.1-10.7.19.85 | 中英文语言文件；`GuiFissionReactor`、`GuiFusionReactorFuel` | 状态／当前运行量／设定上限分开；热量、燃料和统计使用不同区域；数字设置由菜单包提交 |
| Mekanism Extras 1.21.1-1.4.1 | 中英文语言文件；`GuiNaquadahReactorFuel` | 沿用 Mek 输入框、Enter 提交及反应堆侧边标签，不另造一套操作方式 |
| MekMM 1.21.1-1.4.1 | 中英文语言中的 `gui.mekmm.wts.*` 传输统计 | 资源种类、数量与 `/t` 单位明确；不照搬其中不一致的英文大小写或 `mb` 拼法 |

使用语言条目和发布 JAR 的 `javap` 结果核对行为；没有复制第三方实现或素材。Mek 原生的 `MekanismLang.STATUS`、控件和配置窗口直接复用。

## 表述

- **状态描述现在，按钮描述动作。** 例如“状态：能量不足”“启动”“停机”。开关则显示“自动弹出：开／关”。
- **数值名称符合实际含义。** 总发电量为扣除约束耗能前的发电；净发电量为扣除约束耗能后的发电；输出速率为实际送入外部设备的电量。储能与燃料余量不混用。
- **主区域简短，条件放提示。** 调谐按钮只写“耀斑升载”，悬停说明消耗与当前不能使用的原因。观测模式的阈值与红石条件放在对应按钮提示中。
- **不让玩家理解内部实现。** 用“能量源”“输出空间不足”“输入缓存”；不用源核心、已付批次、底层接口或开发版本说明。
- **单位完整且本地化。** 距离为格／blocks，时间为秒／s，速率为 FE/t、mB/t、个/t。省略未选择项时使用“未设置”，不把尚未搜索当作没有设备。
- **中英文同步，修改生成源。** `generate_resources.py` 与 solar／coronal／module 生成器共同维护运行语言资源。注册 ID 和存档字段不因措辞变化重命名。

## 操作

1. 能量源：打开选择器，选装置，点“设置”；列表显示位置、核心状态和可用能量。“断开连接”只移除关联。
2. 频率：在公私有列表选择后点“设置”，或输入名称后设置；同名即选用，没有则新建。“清除”仅退出本节点，“删除”在原生确认框中说明会影响该频率上的所有节点。
3. 列表：按稳定的 UUID／BlockPos 保留选择，避免刷新后误操作相邻行。已设置项不能重复提交。
4. 类型页：在同一窗口切换资源；只显示当前页仪表，隐藏仪表同时停用。六面配置继续决定真实管道接口，无线开关只控制节点间传输。
5. 数字：Enter／勾号提交，输入错误标红并说明范围；旁边的当前值由服务器同步，不提前改成输入草稿。观测比例模式不开放无效的阈值编辑。
6. 验证：资源与编译检查适用于本轮客户端改动；不能据此声称已经通过游戏视觉和鼠标操作验收。
