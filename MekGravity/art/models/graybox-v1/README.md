# 引力堆 · 整机三维灰模 v1

2026-09-22。用户已确认本稿，几何已拆分接入alpha.5。此目录保留灰模，用于继续检查外形、比例、凹凸与连接；游戏模型使用同一份assembly.json。

直接打开index.html即可旋转查看，不依赖网络/CDN；浏览器需要WebGL 2。可切换完整、剖切和内腔视图，拖动爆炸分解滑条，点击模型选择部件，或使用线框检查网格。默认点击穿过玻璃选择设备，Alt+点击可选择玻璃。方向键也可旋转，+/−缩放。灰模默认不使用贴图；“部件分色”仅辅助区分材料。

## 建模文件

- `reactor-graybox.obj` + `reactor-graybox.mtl`：可导入三维编辑器的真实网格，材质文件放在OBJ旁边。每个可选部件对应独立对象，名称包含类型和逻辑坐标。
- `assembly.json`：保留所有立方体边界、材料、部件类型、朝向、方块锚点和合并前玻璃位置，可据此拆回游戏部件。
- `scene.js`：同一份模型数据供本地WebGL预览；无图片伪造的立体效果。
- `concept-reference.png`：最早的原创概念图，只作为设计对照。

## 尺度与变化

一个建模单位等于一个Minecraft方块；结构主体范围0～7，原点位于正面左下角。核心中心为(3.5,3.5,3.5)，六个约束发射器仍使用现有1/5坐标锚点。

立柱由连续护边、内凹主体和独立转角构成。发射器分为安装底板、外壳、收缩颈部和内凹发射口；鼻部伸入原有留空区域0.25格。窗沿为有厚度的独立构件，整面玻璃合并显示。地板、顶板与接口均有真实凹槽。

本稿需要审查的取舍：发射头外伸后，游戏接入时需处理模型边界和选择框；合并玻璃仍对应原来的单块玻璃，不能改变库存或配方数量。剖开模式只隐藏正面玻璃和中间顶板，不代表搭建时可以省略。

alpha.5已完成16×16材料UV、运行模型分拆、结构成型和损坏切换；此离线预览仍展示灰模，不能代替游戏内验收。建模和接入均未调整发电参数。

## 重建

仓库中运行 `python MekGravity/tools/generate_graybox.py`，从模板和当前核心网格生成本目录OBJ、MTL、assembly.json、scene.js及ZIP包。index.html/viewer.css/viewer.js是可维护的预览源文件。

几何为本项目原创，沿用仓库MIT许可证；参考图为此前内置image_gen生成的原创图稿。未使用第三方建模库或模型。
