# 微缩太阳结构草案

这是微缩太阳逻辑占位图，已由alpha.8运行资源生成器使用；图本身不是三维模型。实际使用与首版范围见[SOLAR_README.md](../../SOLAR_README.md)。

`layout.json`保存9×9×9坐标、初稿功率/寿命、材料数量；`layout.svg`展示九层布局。运行 `python MekGravity/tools/generate_solar_plan.py` 重建，脚本检查重叠、数量、中心留空、接口外侧面和四档能量预算。

alpha.8采用的默认数值：毛功率256/512/1024/2048 GFE/t，单份满载16/8/4/2小时，单份737.28 PJ；缓存1.024 PFE、单口1.024 TFE/t额度。脚本检查单份预算long范围、点火/备用电和输出额度。不能将64份预算合并为一个long，FE回退吞吐仍受有界分批限制。

主体220块：69基座、20支撑、48约束环、37冠架、36采能翼、2聚束器、1恒星胚核、1主控、1燃料仓、1点火口、4发电口。角柱与环相交的8格由约束环占据，没有重复计数。

4组采能翼位于四个侧面中心，按3×3逻辑方块占位，后续灰模会将其做成弧形分片采能面。中央太阳体与日冕不额外放置实体方块。现有7格引力堆不使用本结构数据。

玩法、长效燃料、代价、界面和实现范围见 [SOLAR_DESIGN.md](../../SOLAR_DESIGN.md)。所有数值均为初稿，未做游戏内测试。
