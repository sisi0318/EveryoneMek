# 变更记录

## 0.1.0-alpha.16

- 引力堆两道金属约束环接入gravity_ring.vsh／.fsh，保留原几何、反向旋转和负载驱动，增加金属高光、紫色能量槽及环向流动亮点。零纹理与噪声采样，两环仍共192个四边形。
- 恒星引力场接入stellar_field.vsh／.fsh，以单层shader柔边替代双层光带，保留原轨迹与颜色；网格从640减到430个四边形，正常遮挡且不写透明深度。
- 恒星胚核物品接入原NeoForge自定义物品渲染，手持、物品栏、展示框及掉落物使用新版球面shader。命中／破坏粒子改用同shader直接烘焙的16×16颜色，不再引用旧球面像素图。
- 构建、真实隐藏OpenGL shader验证、原环几何逐顶点一致及物品／粒子资源检查通过。没有启动Minecraft客户端，也未重复服务器测试；既有物品和方块无需重建。

## 0.1.0-alpha.15

- 恒星胚核和引力堆能量核均接入专用shader；共享stellar_surface.vsh，分别使用stellar_surface.fsh与gravity_surface.fsh，前者金橙对流，后者深紫能量纹路，原金属约束环保留。
- 为恒星胚核加入专用stellar_surface.vsh／.fsh，三维程序纹理生成连续流动的等离子对流、亮丝和球缘暗化，世界表面不再显示贴图方格。物品图标保留静态材质。
- 单次不透明表面绘制，零纹理采样、无全屏后处理或光线步进；三档缓存网格864／384／96四边形，远处减少细节并让约束场在40～48格淡出。复用坐标临时对象，避免每顶点创建临时向量。
- 相位／热态按顶点传递，支持多核心独立动画和正常深度遮挡；资源重载通过原NeoForge shader注册回调更新，加载失败保留静态模型回退。热态、发电及存档保留。
- 恒星中心0.45格新增默认100万点热伤，最外球面及更远区域保留原2／4／8点伤害；胚核允许穿过以真实接触中心。新增致命警告沿用huige233参考色散字体，伤害可配置，尊重正常抗火/保命机制。
- 构建与独立隐藏OpenGL实测通过，验证真实.vsh／.fsh编译链接、多核心、冷热、动画、遮挡和三档闭合网格。21项服务端GameTest通过，新增200生命生物中心接触致死、外围不误杀、抗火与熄火回归。未启动游戏客户端；离线GPU时间不是游戏帧率测试。
