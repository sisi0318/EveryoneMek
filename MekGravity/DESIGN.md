# 引力堆原型的实现取舍

完整设计背景与视觉草图位于 [机制提案](../docs/MEK_GRAVITY_REACTOR_DESIGN.md) 和 [设计包](../docs/gravity-reactor/README.md)。当前行为以本项目 README 为准。

原型沿用7×7×7、六轴线圈、225方块默认蓝图；四级线圈取最低等级，正常功率为0.5/1/2/4 GFE/t。独立模组依赖 Mek 与 Mek Generators，不强制要求并行工厂或 Extras。

能量、钠、热钠和反应余量由主控持有；燃料仓独立持有18格原料。资源接口只是实际存储的视图。所有能量口共享整堆预算，每个口另有单口预算，两者都按世界 tick 结算。

燃料配方提供有限 J 预算，分成毛发电与冷却热焓两部分；毛发电的2%为约束自耗。读取冷/热钠数据时取两侧热焓中的较大值，防止数据包把热钠回收热量提高后凭空增加能源。

正常运行逐 tick 升载，最高每 tick 增加额定功率的5%；资源不足时立即限流。首次建立约束需要64 GFE，另留2 GFE保护储能。正常停机保留已建立状态，避免重复收取巨额点火费用。首版不模拟离线热衰减或事故。

本版将“约束稳定度”简化为实际建立状态与备用电条件，避免给没有模拟依据的数字。冷却不足和出口满各有明确提示，受限时不吃料。高级危险/超载模式留在后续。

模型使用原生方块尺度。初版黑色球壳与alpha.3方形护架均已淘汰；alpha.4按用户确认改为悬浮深紫能量球与两道细金属环。发光环属于纯客户端效果，无世界伤害或物料扫描。生成图与离线模型投影均不作为游戏截图。


## alpha.2 的用户修订

用户明确反馈玻璃、主控UI、输出限速、成型外观，并认为引力场不应强制使用钠，要求增加特效及发电效率。现以README中的当前行为为准，上述初版钠循环是历史设计。

- 默认蓝图移除两个冷却接口，改放玻璃，仍为225个方块。旧接口和化学品只用于回收，不阻止旧结构运行。
- 默认发电与燃料能值同时提高4倍，维持原有的大致供料节奏；输出与输入额度各由对应端口数量决定，每口16 GFE/t。
- 成型外观使用实际formed方块状态，更新会自然触发区块重绘；该状态变化不参与结构失效，避免换肤触发拆坏/重组循环。
- 玻璃按渲染区域的26邻格生成面数据，每个面分成4条边和4个角。保留缺失对角格的内角，不复制一整圈厚边框。
- 特效是固定数量的客户端网格，使用弱引用保存淡入淡出状态，不生成服务器实体或按FPS生成粒子。

## alpha.4 的外观修订

以整机重复铺贴效果为准：框架、顶板和机壳减少内部线条，成型仅改变少量角标颜色；不再将单个机器面板密集铺到整面墙。核心外形与普通机器区分，能量球和两道薄环使用固定低多边形模型，共用方块/物品几何；近景与整机尺度分别预览。

## 整机灰模与接入（2026-09-22）

用户指出当前模型与最早概念相差较大，并要求改用整机建模。先交付可旋转的真实灰模，确认轮廓与比例，再做材质与游戏接入。[三维预览](art/models/graybox-v1/index.html)与[建模说明](art/models/graybox-v1/README.md)记录具体取舍。

这一稿以连续立柱、独立转角、阶梯式发射头、内嵌窗沿、内凹底顶板和厚接口为主体。用户确认后在alpha.5拆分接入：保留原有方块锚点，窗框用邻接模型合并显示，玻璃仍各自对应原方块；发射头向内伸出0.25格，选择框和碰撞来自同一几何。游戏使用原有16×16材料贴图的UV区域，原有发电、物流和存档数据不变。

## alpha.7 运行动画

用户要求运行时核心动起来。保持已确认的内核与两环几何，分体自转、双环反转；加入内核微浮动和呼吸、追逐光弧与六向汇聚光点。实际发电负载驱动强度，电满/缺料/停机收束，停机保留实体核心。发电规则不受动画影响。物品模型静止，世界核心由单一动态渲染路径绘制，避免重影；运动只用客户端世界时间，服务端限频同步一字节外观负载。
