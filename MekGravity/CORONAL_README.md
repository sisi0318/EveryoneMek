# 日冕加工舱 · alpha.26

把微缩太阳的高温用于批量熔炼和合金精炼。现有太阳不必重建，加工舱是可选的外置模块。

## 安装与使用

1. 在一组 **3×3 采能翼的外侧中心** 放置加工舱，舱体背面贴着翼片，开口朝外。四组采能翼各可安装一台。可用配置器调整水平朝向。
2. 点燃太阳，并保持太阳和加工舱启用。缓存充满后的高温待机也可加工；太阳停机、结构损坏或红石禁止运行时暂停。
3. 从左右、上方或下方输入原料，正面连接箱子或物品管道接收产物。每舱独立 **9 格输入＋9 格输出**，普通64堆叠材料每格最多 **4,096个**，输入／输出分别合计 **36,864个**；16堆叠材料每格1,024个，不可堆叠物仍为1个，默认向正面自动弹出。
4. 右键打开加工舱查看进度、批量、加工耗能，切换暂停或自动输出。

加工直接使用太阳缓存，保留约束备用电。每个服务器 tick 先执行太阳主动出电，再分配新批次的加工用电；外部设备主动抽电的先后仍取决于服务器调度。不会降低玩家设置的发电上限，也不会生成免费的电量。加工舱的拥有者需有权使用该太阳。

## 加工能力

- 普通材料优先使用高炉配方，没有时使用熔炉配方；无需额外燃料，不生成经验球。
- 默认每批最多 **512份**，额外加工加速为 **5倍**；约束部件等级为初级／高级／精英／终极时，普通熔炼时长分别为 **8／4／2／1 tick**。满批时每舱吞吐为 **1,280／2,560／5,120／10,240份每秒**（20 TPS），四舱合计最高 **40,960份/秒**。这些数值针对1原料→1产物的普通熔炼，供料和接收设备需跟得上。原生漏斗无法提供这个吞吐。
- 普通熔炼每份消耗 **1 GJ**，默认 Mek 换算为 **400 MFE**。开工时一次消耗整批所需电量，等级加速不增加每份耗电。输入或输出库存改变后立即重新尝试；无变化的空闲状态每5 tick重试。成品完成后立即尝试向正面弹出。
- 附带三种高温合金配方，JEI 可查看。铜锭＋红石制备基础合金；四份基础合金＋一份富集钻石制备四份强化合金；两份强化合金＋一份富集精炼黑曜石制备两份原子合金。后两项分别要求高级、精英约束部件，沿用当前 Mek 的物料比例。
- 普通熔炼批量、时长、单份电量在 `mekgravity-solar-server.toml` 的 `coronalBatchSize`、`coronalSmeltingTicks`、`coronalSmeltingEnergy`，以及同时影响专用配方的 `coronalAcceleration` 中配置。能量单位为 J。

先检查产物空间，再扣料和电量。开工后保存在制产物与进度；暂停、卸载、保存重载、拆下再放置均不重复耗料耗能。完成时若产物空间被占满，保留待输出物；已完成的批次可在太阳熄火后进入输出槽。取消暂停即可继续未完成批次，不退回已消耗的原料。

## 升级旧版本

旧版默认批量32和单份5 GJ在首次加载时自动更新为512和1 GJ；非默认自定义值保留，迁移只执行一次。新增 `coronalAcceleration` 默认为5，设为1可取消额外加速。已开工批次继续使用原时长、已消耗电量和产物，不重复耗料耗能。现有18个槽位的顺序、物料和设置保留，原位置上的舱体自动使用新模型。

alpha.23起，源太阳选择“加工聚焦”调谐后，新批次再加速2倍，最低1tick；源发电量相应降至80%。旧批次不改时长。详见[核心调谐器](ORBITAL_MODULES.md)。

## 数据包扩展

`data/<命名空间>/recipe/<文件名>.json` 使用 `mekgravity:coronal_processing`：

```json
{
  "type": "mekgravity:coronal_processing",
  "inputs": [
    {"ingredient": {"tag": "c:ingots/copper"}, "count": 1},
    {"ingredient": {"item": "minecraft:redstone"}, "count": 1}
  ],
  "result": {"id": "mekanism:alloy_infused", "count": 1},
  "ticks": 40,
  "energy": 1000000000,
  "tier": 0
}
```

支持 1～4 组物品／标签输入，每组 1～64 个；可以分散在多个槽中。`tier` 为最低约束等级 0～3；`ticks` 为基础时长 1～72000，除以额外加速倍率与实际约束等级倍率并向上取整，最少1 tick；`energy` 为每份配方总能量 1～10¹² J；结果 1～64 个。专用配方优先于普通熔炼。数据包重载只影响下一批，不重算已付费工作。

alpha.22清理舱体、侧板和边框的重叠表面，修复转动视角时的斜纹闪烁；不改变形状、容量、吞吐、库存和加工进度。

## 视觉与验证

深灰扁平舱体与窄白灰轨条复用本模组原创16×16材质，通过背部接合板贴合采能翼；轮廓、碰撞框和手持模型同步更新；悬浮物料随热环流动，独立 `coronal_processing.vsh/.fsh` 表现橙金色加热纹路。完整／简化模式分别为 128／48 个四边形，无贴图采样、粒子实体或全屏后处理；遵循现有特效距离、关闭与 shader 回退设置。

alpha.21通过真实服务器tick测试四翼／四等级的持续吞吐，以及36,864缓存的原生保存、菜单提取／合并和掉落后重放；没有修改正常手持物品的堆叠上限。无界面测试覆盖真实漏斗供料与箱子出料、分散输入、合金配方、等级限制、原生右键菜单，以及付费批次保存／掉落／真实重放／堵塞／熄火。隐藏 OpenGL 检查实际 shader 的编译、流动、停机与遮挡。未启动游戏客户端，游戏内视觉由用户验收。
