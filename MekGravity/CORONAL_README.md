# 日冕加工舱 · alpha.20

把微缩太阳的高温用于批量熔炼和合金精炼。现有太阳不必重建，加工舱是可选的外置模块。

## 安装与使用

1. 在一组 **3×3 采能翼的外侧中心** 放置加工舱，舱体背面贴着翼片，开口朝外。四组采能翼各可安装一台。可用配置器调整水平朝向。
2. 点燃太阳，并保持太阳和加工舱启用。缓存充满后的高温待机也可加工；太阳停机、结构损坏或红石禁止运行时暂停。
3. 从左右、上方或下方输入原料，正面连接箱子或物品管道接收产物。每舱独立 **9 格输入＋9 格输出**，默认向正面自动弹出。
4. 右键打开加工舱查看进度、批量、已付能量，切换暂停或自动输出。

加工直接使用太阳缓存，保留约束备用电。每个服务器 tick 先执行太阳主动出电，再分配新批次的加工用电；外部设备主动抽电的先后仍取决于服务器调度。不会降低玩家设置的发电上限，也不会生成免费的电量。加工舱的拥有者需有权使用该太阳。

## 加工能力

- 普通材料优先使用高炉配方，没有时使用熔炉配方；无需额外燃料，不生成经验球。
- 默认每批最多 **32 份**，普通熔炼基本时长 **40 tick**；约束部件等级为初级／高级／精英／终极时，时长分别为 **40／20／10／5 tick**。满批、材料和供能充足时，每舱理论吞吐为 **16／32／64／128 份每秒**（20 TPS）。
- 普通熔炼每份消耗 **5 GJ**，默认 Mek 换算为 **2 GFE**。开工时一次支付整批费用，等级加速不增加每份耗电。等待物料或空间时每 5 tick 重试。
- 附带三种高温合金配方，JEI 可查看。铜锭＋红石制备基础合金；四份基础合金＋一份富集钻石制备四份强化合金；两份强化合金＋一份富集精炼黑曜石制备两份原子合金。后两项分别要求高级、精英约束部件，沿用当前 Mek 的物料比例。
- 普通熔炼批量、时长、单份电量在 `mekgravity-solar-server.toml` 的 `coronalBatchSize`、`coronalSmeltingTicks`、`coronalSmeltingEnergy` 中配置。能量单位为 J。

先检查产物空间，再扣料和电量。开工后保存已经支付的产物与进度；暂停、卸载、保存重载、拆下再放置均不重新收费。完成时若产物空间被占满，保留待输出物；已完成的批次可在太阳熄火后进入输出槽。取消暂停即可继续未完成批次，不退回已支付的原料。

## 数据包扩展

`data/<命名空间>/recipe/<文件名>.json` 使用 `mekgravity:coronal_processing`：

```json
{
  "type": "mekgravity:coronal_processing",
  "inputs": [
    {"ingredient": {"tag": "c:ingots/copper"}, "count": 1},
    {"ingredient": {"item": "minecraft:redstone"}, "count": 1}
  ],
  "result": {"id": "mekanism:alloy_infused", "count": 1},
  "ticks": 40,
  "energy": 5000000000,
  "tier": 0
}
```

支持 1～4 组物品／标签输入，每组 1～64 个；可以分散在多个槽中。`tier` 为最低约束等级 0～3；`ticks` 为基础时长 1～72000，按实际约束等级加速；`energy` 为每份配方总能量 1～10¹² J；结果 1～64 个。专用配方优先于普通熔炼。数据包重载只影响下一批，不重算已付费工作。

## 视觉与验证

白灰舱体复用本模组原创 16×16 材质；悬浮物料随热环流动，独立 `coronal_processing.vsh/.fsh` 表现橙金色加热纹路。完整／简化模式分别为 128／48 个四边形，无贴图采样、粒子实体或全屏后处理；遵循现有特效距离、关闭与 shader 回退设置。

无界面测试覆盖真实漏斗供料与箱子出料、分散输入、合金配方、等级限制、原生右键菜单，以及付费批次保存／掉落／真实重放／堵塞／熄火。隐藏 OpenGL 检查实际 shader 的编译、流动、停机与遮挡。未启动游戏客户端，游戏内视觉由用户验收。
