# Mek Gravity · 引力约束反应堆

**0.1.0-alpha.26** · Minecraft 1.21.1 · NeoForge 21.1.241 · Java 21

一台 7×7×7 后期多方块发电机。六组线圈约束引力核心，持续消耗致密燃料丸；电力维持约束，**不再需要钠冷却**。

同一模组还提供9×9×9的[人造微缩太阳](SOLAR_README.md)：长效恒星燃料、四组采能翼、充满缓存后待机、残余燃料回收，以及随运行负载变化的引力约束场。恒星胚核与引力堆能量核均使用独立shader表面：金橙等离子体与深紫流动能量，约束环也使用带流动发光槽的金属shader。两种核心的手持、物品栏、掉落物与破坏粒子均已统一到新版外观。未熄火的恒星周围会预警并造成分级灼伤，维护前先停机。下方为原引力堆说明；[太阳设计](SOLAR_DESIGN.md)和[追加候选](SOLAR_EXPANSIONS.md)中尚未完成的功能会逐步补充。

新增[日冕加工舱](CORONAL_README.md)：挂在采能翼外侧，用太阳储能批量熔炼和精炼合金，每舱最高10,240份/秒、两侧各36,864物料缓存，配套贴合采能翼的扁平舱体与动态热环 shader。

新增[五台场域扩展机器](ORBITAL_MODULES.md)：耀斑捕获、引力锻造、核心调谐、引力物流和恒星观测。链接器对空气右键打开可视化连接面板，自动发现附近设备，拖线绑定能源或收发节点；物流支持物品、能量、流体和化学品即时传输，耀斑晶核使用独立shader。

## 安装

客户端和服务端安装同一版本的本模组、**Mekanism 1.21.1-10.7.19.85** 与同版本 **Mekanism Generators**。JEI 可选，不要求安装 MekFactory 或 Extras。

JAR：`build/libs/MekGravity-0.1.0-alpha.26.jar`。

升级时先退出游戏，用新版JAR替换mods内的旧版，目录中只保留一个MekGravity。立体框架、阶梯式线圈和内嵌观察窗从alpha.5开始提供，alpha.8包含这些模型；仍加载alpha.4时不会看到新造型。客户端和服务端一起更新，已有引力堆无需重建，微缩太阳另行建造。

用户确认的[整机三维灰模](art/models/graybox-v1/index.html)已拆成游戏模型接入alpha.5，可继续用预览查看几何和分解结构。[OBJ建模包](art/models/graybox-v1/reactor-graybox-v1.zip)保留可编辑源稿。

## 建造与使用

1. 放下主控，下面预留一层空间，左右各三格、背后六格留空。
2. 左侧结构窗口选择**建造等级**，再查看预览／材料清单并一键搭建。材料不齐时先放已有部分，补齐材料后再次点击；只扣成功放置的方块。已有高级线圈会保留。停机后可点**整组升级**，用所选等级的完整部件替换较低级线圈；旧部件退回背包，装不下则掉落在玩家旁。领地保护拒绝时停止并保留已完成部分，受拒绝的部件与材料不变。
3. 正面左侧燃料仓放入致密燃料丸，也可用物品管道供料；正面右侧励磁口接外部电源。
4. 默认首次启动消耗 **64 GFE**，另留 **2 GFE** 备用电，共需至少 **66 GFE**。点击启动后等待充能；主界面显示已充电量和所需电量。
5. 从背面四个发电口向外供电，自动弹出每tick轮换优先接口，减少低供电下的长期偏供。正常启停不重复支付首次启动电费。

能量窗口可翻页查看每个能量接口的位置、输入／输出模式和实际吞吐，主界面显示备用燃料份数。引力堆补满最后一点缓存后停止耗料，结构变化由完整343格范围监听，补建不再等待一秒轮询。

燃料仓支持普通点击与Shift快捷转移，合并或部分取出后会及时保存库存。

配置器潜行右键能量接口切换输入/输出；潜行右键线圈改变朝向。任意框架、外壳、玻璃或线圈可打开主控，燃料仓打开独立的18格库存。

测试时可将创造能量立方直接贴在励磁输入口，接触面设为输出并开启自动弹出。线缆和接收设备自身的容量、吞吐仍会限制实际速度。

## 结构和外观

默认蓝图共225个方块、118格空气：68框架、50外壳、93玻璃、1主控、1燃料仓、5能量接口、6线圈和1核心。五个能量接口默认一个输入、四个输出。[七层图](../docs/gravity-reactor/layers.svg)对应此布局。

核心居中，六个方向各隔一格放线圈，线圈必须朝向核心。棱角用框架，其余面板可替换成外壳、玻璃或接口。每堆最多8个燃料仓、32个接口。

玻璃仍逐块搭建。成型后成为内嵌的浅色观察窗，边框有实际厚度，相邻窗面不会留下重复框线；L形缺口保留内角。不需要额外连接纹理模组，拆除或补齐后随邻块刷新。

框架自动按所在位置显示为连续立柱、横梁和转角接头。底板、顶板、控制器与接口均有真实凹槽；白灰装甲和深色内衬使用原有16×16材质。六向线圈采用阶梯式发射头，向内伸出¼格，选择框和碰撞随朝向变化。成型、拆坏、修复和重载都会更新外观；无需重建旧反应堆。

引力核心为悬浮的深紫能量球，外围有两道细金属约束环。运行时内核自转、轻微浮动和呼吸缩放，两道金属环反向旋转；追逐光弧环绕核心，六向束流和光点持续向内汇聚。实际发电负载越高，动画越快、束流越亮；启动逐渐加速，停机、缺料或电满时平滑收束。停机后仍能看到完整核心与金属环。

[运行动画预览](art/models/core-motion-v1/index.html)可切换运行/停机和负载，使用游戏模型的几何及相同运动参数，但采用简化着色；实际贴图、玻璃遮挡与光效以游戏为准。[核心静态预览](art/core-and-fuel-preview.png)和[整机组合预览](art/reactor-assembled-preview.png)保留用于检查比例。燃料丸继续使用紫黑压缩燃料与金属束环图标。

## 发电和输电

| 六组线圈中的最低等级 | 毛发电上限 | 满载净发电上限 |
| --- | ---: | ---: |
| 初级 | 2 GFE/t | 1.96 GFE/t |
| 高级 | 4 GFE/t | 3.92 GFE/t |
| 精英 | 8 GFE/t | 7.84 GFE/t |
| 终极 | 16 GFE/t | 15.68 GFE/t |

约束自耗为毛发电的2%，发电量受燃料、负载上限和存储空间限制。逐tick升载，缺料或电满立即限流；普通速度/能量升级不适用于本机，升级六组线圈提高发电能力。

**单口默认16 GFE/t，四个输出口合计可输出64 GFE/t。** 输出上限按端口数量计算，缓存电量可快速放出，不再受线圈发电功率限速。多个接口共享真实储能、整体额度和备用电保护，不会复制电量。

能量明细显示实际输入、实际输出和各自上限。自动弹出同时支持 Mek 的long接口和分批FE传输；每个方向最多64次小额尝试，防止接收器阻塞服务器。外部设备主动抽取时，其每tick调用次数也会影响速度。

数值按 Mek 默认 FE/J 换算。原感应矩阵仍受其供应器总吞吐限制，一个原版终极供应器不能接满此堆。Extras设备可通过标准能力接入，本版未做其专属满载测试。

## 燃料

锇块、铅块、精炼黑曜石块与一个钋球合成8个致密燃料丸。每丸预算 **24 TJ**，默认约 **9.6 TFE**；发电与约束从同一预算支付。alpha.6将单丸能值提高到alpha.5的120倍，发电功率与合成材料不变。

在默认功率、100%负载、20 TPS及持续用电条件下，单丸的满载续航为：

| 最低线圈等级 | 单丸满载时间 |
| --- | ---: |
| 初级 | 4分钟 |
| 高级 | 2分钟 |
| 精英 | 1分钟 |
| 终极 | 30秒 |

低负载或缓存电满时消耗更慢，停机不消耗。背包和仓内未投入反应的旧燃料丸也使用新能值；已经投入的旧反应余量保持原值，用完后下一颗按新能值补充。数据包覆写燃料配方时以数据包为准。

材料投入后变成主控中的有限反应余量，按实际工作扣除。暂停、拆装和重载不会把剩余预算重新算成一整丸；物品仍归各燃料仓保存。

数据包可扩充燃料，JEI的“物质燃料”分类展示输入与预算：

```json
{
  "type": "mekgravity:matter_fuel",
  "ingredient": {"item": "example:compressed_fuel"},
  "count": 1,
  "energy": 24000000000000
}
```

`energy`单位为J，范围1～1,000,000,000,000,000；`count`为1～64。已有反应余量保留投入时的预算，配方变更只影响之后投入的燃料。

## 更新与旧版缓存

更新后无需重建。旧默认功率和1 GFE/t接口上限会一次性升级，非默认配置保留。之后手工调低的数值不会再次被覆盖。

旧冷却口不影响成型，也不再接收新钠。已有钠与热钠原样保留；结构窗口会按需显示“旧版缓存”。停机后可用缓存回收接口配合导管抽走冷钠，输出模式用于取回热钠。回收接口保留原注册ID和合成，只从创造列表隐藏，避免旧存档资源无法取回。

主控保存储能、启动状态、负载、反应余量与旧化学品缓存；燃料仓保存本仓物品。结构损坏或区块卸载立即停工并关闭缓存接口，不补算离线发电。

服务端配置为`mekgravity-server.toml`，能量值均使用J。`powerTier0..3`控制发电，`energyPerPortPerTick`控制输电；原`coolantPerGigaJoule`仅为保留旧配置，不再生效。默认保护停机，不爆炸、不吞方块。

## 验证

alpha.7构建和11项服务端测试通过，新增负载外观同步、20/60/144 FPS下相同转速、暂停/停止，以及外观数据不覆盖库存、不写入存档的验证；既有燃料、结构、方向、物流和回收测试继续通过。动画拆分的球体/金属环与原模型几何、UV一致，动态范围不相交。33张16×16贴图与54个成型窗模型继续保留。浏览器检查了满载、低负载和停止；没有启动Minecraft客户端，游戏内贴图、透光和GUI仍由用户验收。

## 客户端画质

模组列表 → Mek Gravity → 配置 → 客户端，或编辑 `config/mekgravity-client.toml`：

- `worldEffects = "FULL"`：完整动态效果；`REDUCED`：简化场线和网格；`OFF`：静态核心，不显示场线。
- `animateItems`：独立控制手持、物品栏和掉落物动画。
- `shaderMaterials`：关闭后使用静态模型材质，可用于排查光影包兼容问题。
- `effectDistance`：世界特效距离，默认48格。引力核心的外部光效仍最多32格。

简化档将恒星场从430段减至76段。客户端设置不改变实际发电、热态、伤害或服务器库存。
