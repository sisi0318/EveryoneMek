# Mek Gravity · 引力约束反应堆

**0.1.0-alpha.1** · Minecraft 1.21.1 · NeoForge 21.1.241 · Java 21

一台 7×7×7 后期多方块发电机。六组约束线圈围绕引力核心，消耗致密燃料丸，将钠转为过热钠，并向外输出电力。

## 安装

客户端与服务端安装相同版本的本模组、**Mekanism 1.21.1-10.7.19.85** 和 **Mekanism Generators 同版本**。JEI 可选。不要求安装 MekFactory、Extras 或其他 EveryoneMek 扩展。

JAR：`build/libs/MekGravity-0.1.0-alpha.1.jar`。

## 建造和启动

1. 放置“引力约束反应堆”主控。结构向主控背后延伸，底板比主控低一格；左右各延伸三格。
2. 打开左侧结构窗口，使用“结构预览”查看缺件位置与清单。备齐材料后停机使用“一键搭建”，实际消耗背包材料。施工遇到保护或占位会停止，已放部件保留。
3. 右键燃料仓放入致密燃料丸，也可连接物品管道。蓝图的燃料仓在正面左下，励磁输入口在正面右下。
4. 左侧冷却输入口接入钠，热钠输出口接入 Mek 热力锅炉；将锅炉冷却后的钠送回输入口，形成循环。锅炉按自身要求供水、输出蒸汽。
5. 向励磁输入口供电。默认首次启动消耗 **64 GFE**，另保留 **2 GFE** 备用电，因此至少需要 **66 GFE**。点击“启动”后会等待资源齐备，再逐渐升载。
6. 从背面发电口向外供电；也可直接连接感应矩阵端口。开启“自动弹出”后，热钠和电力会主动输出。

配置器在配置模式下**潜行右键冷却或能量接口**切换输入/输出。线圈潜行右键改变朝向，必须朝向中心。右键其他框架、玻璃、外壳或线圈均可打开主控界面；燃料仓打开自己的库存。

主控显示净发电、实际输出、运行状态与反应余量。资源条悬停可看储量，能量、冷却、结构等明细放在左侧。负载设置范围 1～100%，回车或勾号应用，以服务器确认值为准。

## 结构与升级

默认布局共 **225 个方块、118 格空气**：68 框架、50 外壳、91 玻璃、1 主控、1 燃料仓、2 冷却接口、5 能量接口、6 线圈和1核心。五个能量接口中一个用于励磁输入、四个用于发电输出。

棱角必须为框架，六个面中间可使用外壳、玻璃或接口。中心是引力核心；上下左右前后各距离两格放置一个线圈，中间一格空气。其他内腔全部留空。

[七层搭建图](../docs/gravity-reactor/layers.svg)对应默认蓝图。一键搭建用于补齐默认蓝图，不会拆除或替换已有的不同种类部件。手工更换接口位置时，只需满足结构条件；每座最多 8 个燃料仓、32 个接口。

| 六组线圈的最低等级 | 毛发电上限 | 满载净发电上限 |
| --- | ---: | ---: |
| 初级 | 500 MFE/t | 490 MFE/t |
| 高级 | 1 GFE/t | 980 MFE/t |
| 精英 | 2 GFE/t | 1.96 GFE/t |
| 终极 | 4 GFE/t | 3.92 GFE/t |

数值按 Mek 默认 FE/J 换算。约束自耗为毛发电的 2%，满载需要足够燃料与冷却。每个能量接口默认最多传输 1 GFE/t；所有发电口还共用整堆输出上限。实际输电取决于接收端和外部线缆，增加端口不会复制能量。

普通速度、能量升级不用于本机，升级六组线圈提升处理上限。原感应矩阵仍受供应器合计吞吐限制；一个原版终极供应器无法接满此堆的最高输出。Extras 设备可经标准能量接口连接，但本版未做 Extras 满载兼容测试。

## 燃料与冷却

锇块、铅块、精炼黑曜石块和一个钋球可合成 **8 个致密燃料丸**。每丸预算为 **50 GJ**，默认换算约 20 GFE；这份预算共同支付毛发电和冷却带走的热量，毛发电中再扣除约束自耗。

每个燃料仓独立保存18格物品。只有资源足够推进时才从仓中取燃料；已经投入的燃料转成主控内的有限反应余量，用多少扣多少，暂停不会重新变回完整一丸。余料与热钠出口不会与燃料仓库存复制保存。

默认每产生 1 GJ 毛电量需转换 2,000 mB 钠。钠和热钠各有 16,000,000 mB 缓存；锅炉能回收的热焓也从燃料中扣除。核对的是实际 Mek 冷/热钠数据，不凭空附送第二份热能。

燃料配方可由数据包扩充，例如：

```json
{
  "type": "mekgravity:matter_fuel",
  "ingredient": {"item": "example:compressed_fuel"},
  "count": 1,
  "energy": 50000000000
}
```

`energy` 使用 Mek 焦耳，范围 1～1,000,000,000,000,000；`count` 为1～64。JEI 的“物质燃料”分类展示输入与能量预算。已有反应余量保留装料时的能值，配方修改只影响后续装料。

## 停机与保存

电满、缺钠、热钠堵塞或缺料时不继续消耗燃料。点击停机或红石暂停后停止反应，正常启停无需再次支付首次启动电费。备用电不能从普通发电口抽走。

主控保存储能、钠/热钠、启动状态、负载、自动弹出设置及反应余量；每个燃料仓保存本仓物品。拆下后的物品也带走相应数据，重放后恢复。旧接口在结构损坏或部件移除后立即关闭，区块卸载后不补算离线发电。

首版采用保护停机，不爆炸、不吞方块、不制造辐射事故。高负载超载模式和额外专用升级暂未加入。

服务端配置为 `mekgravity-server.toml`。能量参数均使用 J，四级功率、启动电费、缓存、备用电、端口吞吐与钠流量可调整；备用电和首次启动之和超过缓存时会显示配置错误。

## 验证

使用本目录 Wrapper 执行 `build runGameTestServer`。六项服务端集成测试覆盖燃料/热量/启动守恒、模拟操作、停料保护、四口大整数输出、真实线缆充电、施工取消与恢复、配置器、GUI入口、拆装数据，以及热钠通过真实加压导管进入原 Mek 锅炉并冷却回钠。

未运行 Minecraft 客户端。实际界面、模型和 JEI 显示由用户验收；浏览器设计看板是历史草图。最高功率的长期锅炉与输电配置仍需在实际整合包中调试。
