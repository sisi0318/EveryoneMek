# 场域扩展机器 · alpha.25

五台可选机器已加入MekGravity，旧引力堆和微缩太阳不用重建。它们独立放置，通过**场域链接器**接入一台装置；同维度默认最远128格，不主动加载区块。

## 首次连接

1. 制作场域链接器、耀斑捕获器和引力锻造舱。配方可用JEI查看，前两台加工机器不需要恒星合金。
2. 手持链接器，**普通右键**太阳或引力堆的主控／结构部件，记录能源。
3. **普通右键**扩展机器完成能源绑定；物流节点再右键接收端完成配对。捕获器只接太阳，锻造舱只接引力堆，其余机器可接任意一种。
4. 右键机器打开界面。左侧“场域链接与状态”查看绑定坐标、能量、燃料和调谐，或解除链接。

绑定与自动工作都会检查Mek权限。可用电量来自源装置的真实缓存，保留约束备用电；源结构损坏、停机、权限收回或区块未加载时停止推进。新模块由各自的服务器tick调度；保留原多方块能量端口的吞吐规则。

## 耀斑捕获器

绑定运行中的微缩太阳，消耗 **4原子合金＋4石英＋50 GJ** 封装 **1耀斑晶核**。基础时长20tick，按约束等级加速，默认最多64份一批。

晶核用于引力锻造和一次性耀斑升载；它不是能够反复充放电的电池。晶核本体为金属约束框内的橙金流动能量核，GUI、双手、展示框和掉落物使用同一shader与静态回退模型。捕获过程有流动场与悬浮原料。

## 引力锻造舱

绑定运行中的引力堆，提供两条可批量加工的路线：

| 原料 | 产物 | 每份耗电 | 基础时长 |
| --- | --- | --- | --- |
| 4原子合金＋1HDPE片材＋1耀斑晶核 | 4恒星合金 | 2 GJ | 20tick |
| 1耀斑晶核 | 1压缩恒星物质 | 5 GJ | 40tick |

恒星合金用于制作核心调谐器和引力物流节点。压缩路线直接消耗耀斑晶核和加工电量，无需燃料丸。锻造舱使用紫色压缩场，默认最多64份一批。

两台加工机器均有**9格输入、9格输出**，普通材料每格4096个。左右、上下和背面进料，正面出料，默认自动弹出。先检查材料、电量和输出空间，开工时一次消耗；在制产物、已消耗电量和进度随保存及掉落物保留。停机后暂停未完成批次，已经完成的产物仍可交付。输出满时不会丢弃在制品。

## 核心调谐器

绑定后在界面选择模式；设置保存在源核心里，多台调谐器控制同一份状态，拆掉控制台不会抹去设置。

| 模式 | 发电功率倍率 | 新加工批次 | 每单位毛发电的燃料成本 |
| --- | --- | --- | --- |
| 均衡 | 100% | 正常 | 100% |
| 加工聚焦 | 80% | 速度×2，最少1tick | 100% |
| 核心超频 | 125% | 正常 | 115% |

倍率仍受主控设置的负载、剩余燃料、缓存空间和外部接收能力影响。加工加速包含日冕加工舱、耀斑捕获器和引力锻造舱，已付费的旧批次维持原时长；原料或供能不足时无法达到最高速度。

放入耀斑晶核，点击“耀斑升载”：核心正在运行、缓存未满且不在恢复中时消耗1晶核，获得**最多20秒150%发电功率**，期间每单位毛发电消耗130%的燃料。缓存满、停机、燃料耗尽或拆坏时提前结束。自触发起80秒后才能再次触发；计时按加载中的服务器tick推进，不计算离线收益。更换控制台、保存重载或拆下核心均保留恢复时间。

超频与升载增加的损耗会从剩余燃料中实际扣除，不另产生可回收热能。没有默认爆炸、白屏闪光或地形破坏。

## 引力物流节点

支持**物品、FE/J能量、流体和Mek化学品**，包括气体、灌注料、颜料、浆液及放射性化学品。采用同类标准接口的其他模组资源也可接入。

节点输入区的资源直接进入目标输出区，不产生运输实体或距离延迟；每个服务器tick把可接收的资源一次转移。默认物品上限扩至整侧缓存36,864个/tick，能量、流体和化学品按实际存量、接收空间与可付传输耗能决定。外接线缆和机器自身的吞吐、过滤、容量限制仍然有效；未被接收的余量保留在节点。

**新绑定顺序：用同一链接器依次普通右键“能量源 → 发送节点A → 接收节点B”。** A到能源主控、A到B均需同维度且不超过128格，目标区块已加载，并具备双方权限。节点不主动加载区块。

- 发送端从侧面、背面、上下接收资源；接收端正面输出，默认自动弹出。接收端由发送端提供运行电量，不用另外绑定能源。
- 界面左侧“资源传输”分别查看四种资源的输入／输出缓存和发送量，流体与化学品使用原生Mek储罐仪表。双方可以独立暂停某类资源的无线传输，其他通道继续工作；缓存仍可存取，已有输出仍可弹出。
- “场域链接与状态”中可单独断开目标或解绑能源。接收端显示“接收端就绪”，不再误提示必须绑定能源；未绑定坐标显示“—”。
- 链接器提示下一步操作。**潜行对空气右键**只清除手中链接器的选择，不改世界里的连接。原“潜行选择接收端，再点发送端”的方式和旧链接器数据仍可用。
- 接收端满、暂停、权限失效、超出范围或未加载时保留源库存。供能不足时轮换四种资源的处理顺序。

| 资源 | 每侧独立缓存 | 默认传输耗能 |
| --- | --- | --- |
| 物品 | 9格，普通材料共36,864个 | 每个物品1 MJ |
| 能量 | 2.56 PJ，默认换算1.024 PFE | 每次非空能量转移1 MJ |
| 流体 | 4罐，每罐16,000,000 mB | 每mB消耗1 kJ |
| 化学品 | 4罐，每罐64,000,000单位 | 每单位消耗1 kJ |

传输耗能取自绑定源，**不从作为货物的能量中扣除**。只有实际转移才耗能。各罐先合并同种资源，再使用空罐，保留流体组件；物品和资源缓存均随世界、节点掉落物及重新放置保存。节点的化学品缓存保持密封，拆卸时不排空放射性货物。

可另外设置反向链接，但接收资源只进入输出区，不会自动回流到输入区。每个节点仍只有一个发送目标。

## 恒星观测站

可绑定太阳或引力堆。界面显示缓存、净发电、实际外供、当前与备用燃料、核心调谐；这些读数约每5tick刷新。冷态也能读取储能和结构信息。

正面提供红石输出，也支持比较器读取。没有红石启停输入，避免告警反过来控制自己；界面暂停可关闭输出。

- **储能比例**：将源缓存映射到0～15。
- **结构或链接异常**：结构损坏、源被移除、未加载或权限失效时输出15。
- **燃料不足**：无备用燃料，且当前剩余燃料低于所选比例时输出15。
- **储能不足**：源缓存低于所选比例时输出15。

阈值可选10%、25%、50%、75%。投影屏的轨迹高度跟随储能比例；精确数值以界面为准。

## 配置、数据包与更新

`mekgravity-modules-server.toml` 提供 `linkRange`、`processingBatch`、`itemsPerNodePerTick`、`joulesPerTransferredItem`、`joulesPerEnergyTransfer`、`joulesPerFluidMillibucket`、`joulesPerChemicalUnit`。能量字段使用Mek的J，界面按整合包的FE换算显示。旧默认4096个/tick会一次更新至36,864，非默认设置保留。

捕获／锻造使用 `mekgravity:orbital_processing` 配方，JEI按机器分类显示。例如：

```json
{
  "type": "mekgravity:orbital_processing",
  "machine": "gravity_forge",
  "inputs": [
    {"ingredient": {"item": "mekanism:alloy_atomic"}, "count": 4},
    {"ingredient": {"item": "mekanism:hdpe_sheet"}, "count": 1},
    {"ingredient": {"item": "mekgravity:flare_cell"}, "count": 1}
  ],
  "result": {"id": "mekgravity:stellar_alloy", "count": 4},
  "ticks": 20,
  "energy": 2000000000,
  "tier": 0
}
```

`machine` 只接受 `gravity_forge` 或 `flare_captor`；1～4组输入，每组1～64个，支持物品标签；结果1～64个；时长1～72000tick；每份能耗1～10¹⁴ J；最低约束等级0～3。材料齐全时，优先匹配输入组更多的配方；该配方因供能或产物空间不足暂停时，不会转而消耗晶核制作简易配方。数据包重载只影响下一批。

客户端和服务端一起替换为alpha.25并重启，保留原有库存、进度和燃料。旧核心缺省为均衡模式；原日冕加工舱的容量、吞吐和防闪烁模型继续保留。

## 验证与外观

五台机器使用独立立体模型及原创16px材质，几何生成先移除共面重叠；碰撞来自相同实体盒。关键工作区使用 `orbital_module.vsh/.fsh`：三种流动场和两种投影屏。场完整128／简化48面，屏幕1面，无粒子实体、纹理采样或全屏后处理，沿用客户端特效开关、距离和shader回退。

服务端测试覆盖原装置回归，以及真实右键链接、捕获出料、锻造拆装续作、节点堵塞／10000物品守恒、权限与范围拒绝、调谐燃料守恒／恢复时间持久化和真实红石灯。隐藏OpenGL已验证五种shader的编译、动态、停止和遮挡。未启动Minecraft客户端，游戏内视觉与JEI完整布局仍由用户验收。

alpha.25共45项服务端测试通过，新增四类资源同tick传递与组件保留、原生FE/J与储罐接口、满端与独立开关、核废料和双向缓存的真实掉落重放，以及对原Mek加压反应室的四种资源出料。耀斑晶核shader经过隐藏OpenGL编译、动画、遮挡及同批次状态验证；GUI使用384面，其他物品场景96面，无纹理采样或全屏效果。
