# 场域扩展机器 · alpha.29

五台可选机器已加入MekGravity，旧引力堆和微缩太阳不用重建。它们独立放置，通过**场域链接器**接入一台装置；同维度默认最远128格，不主动加载区块。

## 首次连接

1. 制作场域链接器和需要的扩展机器。配方可用JEI查看，捕获器与锻造舱不需要恒星合金。
2. 手持链接器，**对空气普通右键**打开场域连接面板；也可以点击扩展机器界面左侧的“网”按钮。
3. 从核心右侧的**金色连接点**拖到模块左侧金色点，为模块绑定能源。捕获器只接太阳，锻造舱只接引力堆，其余机器可接任意一种。
4. 物流节点打开“选择频率”，在各节点使用同一频率，再用左侧原生六面配置设置资源输入输出。同频组只需为一个可用节点绑定能源。

也可以先点击输出点，再点击同色输入点或目标卡片；右键或Esc取消未完成连线。链接器也可以依次右键能源和模块完成供能绑定。节点之间统一使用频率。

## 场域连接面板

面板每秒自动识别附近**已加载且有访问权限的核心主控和五种可绑定模块**，默认同维度128格。不会扫描任意箱子或其他模组机器；这些设备通过管道接物流节点。固定挂在采能翼上的日冕加工舱不需要手动绑定。

- 金线表示能源绑定，不可用时显示红色虚线。蓝框标识使用频率的物流节点，卡片显示频率名称；不再用蓝线逐对连接节点。节点之间及发送节点到供能核心仍受当前连接距离限制，默认128格。
- 搜索栏右侧“范围设置”可分别输入**扫描范围**和**连接距离**，均为16～512格，回车或勾号保存。上方读数显示服务端确认的数值。
- 扫描范围只影响个人面板，保存到玩家数据，重新打开、重登和重生后保留；缩小后隐藏的设备与既有绑定不会删除，下一次自动扫描在1秒内刷新。首次打开默认采用当前服务端连接距离。
- 连接距离影响当前服务器的能源绑定与节点传输，限单人存档主人或拥有2级以上OP权限的玩家修改；普通玩家只能查看。修改立即生效并保存当前生效配置的`linkRange`：默认是`config/mekgravity-modules-server.toml`，若存档已有同名`serverconfig`覆盖文件则保存该文件。超距旧线路暂停，恢复距离后可继续使用，不清空绑定或资源。
- 搜索名称或坐标；拖卡片标题调整位置，拖空白平移、滚轮缩放。用“整理布局”和“适应视图”恢复清楚的排列。只画当前可见端点之间的连线，详情仍显示已绑定坐标。
- 点击连线，再按Delete断开；选中模块也可以用底部“解绑能源”“离开频率”。选中物流节点后，底部四个开关立即控制该节点实际的物品、能量、流体和化学品传输。
- 自动扫描最多显示最近192台设备，底栏显示总数。权限收回、设备拆换或离开范围后不能继续用旧面板改链接。
- 工具打开时以开面板的位置为中心，需要保持手持链接器且距离不超过8格；机器打开时以该机器为中心，保持在8格内。面板设置不搬动库存；旧链接与掉落物数据保持兼容。

绑定与自动工作都会检查Mek权限。可用电量来自源装置的真实缓存，保留约束备用电；源结构损坏、停机、权限收回或区块未加载时停止推进。新模块由各自的服务器tick调度；保留原多方块能量端口的吞吐规则。

## 耀斑捕获器

绑定运行中的微缩太阳，消耗 **4原子合金＋4石英＋50 GJ** 封装 **1耀斑晶核**。基础时长20tick，按约束等级加速，默认最多64份一批。

晶核用于引力锻造和一次性耀斑升载；它不是能够反复充放电的电池。晶核本体为橙金流动能量球，外侧仅有细八边约束环和两处小磁极，GUI、双手、展示框和掉落物使用同一shader；关闭shader时仍保留球形。捕获过程有流动场与悬浮原料。

## 引力锻造舱

绑定运行中的引力堆，提供两条可批量加工的路线：

| 原料 | 产物 | 每份耗电 | 基础时长 |
| --- | --- | --- | --- |
| 4原子合金＋1HDPE片材＋1耀斑晶核 | 4恒星合金 | 2 GJ | 20tick |
| 1耀斑晶核 | 1压缩恒星物质 | 5 GJ | 40tick |

恒星合金用于制作核心调谐器和引力物流节点。压缩路线直接消耗耀斑晶核和加工电量，无需燃料丸。锻造舱使用紫色压缩场，默认最多64份一批。

两台加工机器均有**9格输入、9格输出**，普通材料每格4096个。左右、上下和背面进料，正面出料，默认自动弹出。先检查材料、电量和输出空间，开工时一次消耗；在制产物、已消耗电量和进度随保存及掉落物保留。停机后暂停未完成批次，已经完成的产物仍可交付。输出满时不会丢弃在制品。

## 核心调谐器

绑定后在界面选择模式；设置保存在源核心里，多台调谐器控制同一份状态，拆掉控制台不会抹去设置。

| 模式 | 发电功率倍率 | 新加工批次 | 每单位毛发电的燃料成本 |
| --- | --- | --- | --- |
| 均衡 | 100% | 正常 | 100% |
| 加工聚焦 | 80% | 速度×2，最少1tick | 100% |
| 核心超频 | 125% | 正常 | 115% |

倍率仍受主控设置的负载、剩余燃料、缓存空间和外部接收能力影响。加工加速包含日冕加工舱、耀斑捕获器和引力锻造舱，已付费的旧批次维持原时长；原料或供能不足时无法达到最高速度。

放入耀斑晶核，点击“耀斑升载”：核心正在运行、缓存未满且不在恢复中时消耗1晶核，获得**最多20秒150%发电功率**，期间每单位毛发电消耗130%的燃料。缓存满、停机、燃料耗尽或拆坏时提前结束。自触发起80秒后才能再次触发；计时按加载中的服务器tick推进，不计算离线收益。更换控制台、保存重载或拆下核心均保留恢复时间。

超频与升载增加的损耗会从剩余燃料中实际扣除，不另产生可回收热能。没有默认爆炸、白屏闪光或地形破坏。

## 引力物流节点

参考Mek量子传送装置的频率选择和六面配置，使用引力节点自己的频率。支持**物品、FE/J能量、流体和Mek化学品**，包括气体、灌注料、颜料、浆液及放射性化学品；相同标准接口的模组资源也可以接入。

1. 放置节点，打开“选择频率”。选择私有或公开，输入名称后回车／点勾创建并使用；其他节点从同类频率列表选中后点“使用”。私有频率仅创建者可选，公开频率可共享；删除频率仅限创建者。
2. 左侧原生Mek六面配置中，分别选择物品、能量、流体和化学品，再设置各面输入、输出、双向或关闭。**发送节点接输入面，接收节点接输出面**；不需要固定朝向，也不需要指定一个接收节点。单个面的配置变化会同时影响实际接口和自动出料。
3. 点“能源绑定”打开场域面板，从引力堆或太阳拉金线到组内一个节点。组内发送节点可使用已绑定的可访问能源；仍需在核心的连接范围内。可用能源较多时优先使用余量充足的一台。
4. 接上管道即可运行。“发送缓存”保存本机输入，“接收缓存”保存接收到的资源；资源页查看四种缓存和传输量，能量页显示本机传输耗能。四种无线通道可分别开关。

同频节点在同一维度、加载区块且符合Mek权限及距离要求时自动分发，不产生运输实体或旅行延迟。轮换接收端，满端保留余量；接有出料设备的节点优先，避免把资源塞入闲置节点。没有外接接收设备时，可配置输出面后用本机接收缓存手动取用。节点不强制加载区块。

默认同维度连接距离128格，可在面板“范围设置”调整到16～512格。绑定能源的节点和实际发送节点都须在能源范围内；节点之间也遵守该距离。节点暂停会停止本机无线收发，已经收到的资源仍可由输出面取出。

| 资源 | 每侧独立缓存 | 默认传输耗能 |
| --- | --- | --- |
| 物品 | 9格，普通材料共36,864个 | 每个物品1 MJ |
| 能量 | 2.56 PJ，默认换算1.024 PFE | 每次非空能量转移1 MJ |
| 流体 | 4罐，每罐16,000,000 mB | 每mB消耗1 kJ |
| 化学品 | 4罐，每罐64,000,000单位 | 每单位消耗1 kJ |

物品每个发送节点每tick最多36,864个；其他资源按现有存量、接收空间与可支付耗能搬运。外接机器和管道的容量、过滤和速率仍然有效。运行耗能取自绑定核心，**不消耗作为货物传送的能量**。

频率只保存名称、权限和连接身份，物料始终保存在真实节点里。离开、改选或删除频率不会清空缓存；本版本的节点拆放会保存频率、六面配置与全部资源，核废料等化学品保持密封。

节点为带内凹投影窗的工业机壳。工作时显示实际传输类型：物品材质、能量闪电、流体或化学品纹理／颜色；同时传多类资源时轮换显示，停止后淡出。投影使用独立shader，每节点一个小面片，受客户端特效开关和距离限制。

**开发期破坏性更新：alpha.29已移除旧的发送端／接收端配对、潜行配对和相关数据读取，没有旧节点迁移。旧节点请重新放置并选择频率、配置接口及能源。**

## 恒星观测站

可绑定太阳或引力堆。界面显示缓存、净发电、实际外供、当前与备用燃料、核心调谐；这些读数约每5tick刷新。冷态也能读取储能和结构信息。

正面提供红石输出，也支持比较器读取。没有红石启停输入，避免告警反过来控制自己；界面暂停可关闭输出。

- **储能比例**：将源缓存映射到0～15。
- **结构或链接异常**：结构损坏、源被移除、未加载或权限失效时输出15。
- **燃料不足**：无备用燃料，且当前剩余燃料低于所选比例时输出15。
- **储能不足**：源缓存低于所选比例时输出15。

阈值可选10%、25%、50%、75%。投影屏的轨迹高度跟随储能比例；精确数值以界面为准。

## 配置、数据包与更新

`mekgravity-modules-server.toml` 提供 `linkRange`、`processingBatch`、`itemsPerNodePerTick`、`joulesPerTransferredItem`、`joulesPerEnergyTransfer`、`joulesPerFluidMillibucket`、`joulesPerChemicalUnit`。能量字段使用Mek的J，界面按整合包的FE换算显示。旧默认4096个/tick会一次更新至36,864，非默认设置保留。

捕获／锻造使用 `mekgravity:orbital_processing` 配方，JEI按机器分类显示。例如：

```json
{
  "type": "mekgravity:orbital_processing",
  "machine": "gravity_forge",
  "inputs": [
    {"ingredient": {"item": "mekanism:alloy_atomic"}, "count": 4},
    {"ingredient": {"item": "mekanism:hdpe_sheet"}, "count": 1},
    {"ingredient": {"item": "mekgravity:flare_cell"}, "count": 1}
  ],
  "result": {"id": "mekgravity:stellar_alloy", "count": 4},
  "ticks": 20,
  "energy": 2000000000,
  "tier": 0
}
```

`machine` 只接受 `gravity_forge` 或 `flare_captor`；1～4组输入，每组1～64个，支持物品标签；结果1～64个；时长1～72000tick；每份能耗1～10¹⁴ J；最低约束等级0～3。材料齐全时，优先匹配输入组更多的配方；该配方因供能或产物空间不足暂停时，不会转而消耗晶核制作简易配方。数据包重载只影响下一批。

客户端和服务端一起替换为alpha.29并重启，引力堆与太阳的原有库存、进度和燃料不变。物流节点按本节的新频率流程重新配置；旧核心缺省为均衡模式；原日冕加工舱的容量、吞吐和防闪烁模型继续保留。

## 验证与外观

五台机器使用独立立体模型及原创16px材质，几何生成先移除共面重叠；碰撞来自相同实体盒。关键工作区使用 `orbital_module.vsh/.fsh`：三种流动场和两种投影屏。场完整128／简化48面，屏幕1面，无粒子实体、纹理采样或全屏后处理，沿用客户端特效开关、距离和shader回退。

服务端测试覆盖原装置回归，以及真实右键链接、捕获出料、锻造拆装续作、节点堵塞／10000物品守恒、权限与范围拒绝、调谐燃料守恒／恢复时间持久化和真实红石灯。隐藏OpenGL已验证五种shader的编译、动态、停止和遮挡。未启动Minecraft客户端，游戏内视觉与JEI完整布局仍由用户验收。

alpha.25共45项服务端测试通过，新增四类资源同tick传递与组件保留、原生FE/J与储罐接口、满端与独立开关、核废料和双向缓存的真实掉落重放，以及对原Mek加压反应室的四种资源出料。耀斑晶核shader经过隐藏OpenGL编译、动画、遮挡及同批次状态验证；GUI使用384面，其他物品场景96面，无纹理采样或全屏效果。

alpha.26共48项服务端测试通过；新增真实工具／机器界面打开面板、自动发现、两类连线绑定后实际物流、通道开关、断线保留资源、两种数据包编解码，以及权限收回／超距／替换设备／旧会话拒绝。面板的游戏内视觉和拖线手感仍由用户验收。

alpha.27共49项服务端测试通过。范围回归覆盖设置包数值往返、扫描偏好重新打开、普通玩家拒绝／OP允许／OP收回、200格真实节点绑定、缩小连接暂停与恢复、扫描缩小不清空库存和绑定，以及畸形范围拒绝。测试在finally恢复全服配置和OP，不改用户存档。

alpha.29共52项服务端测试通过。原节点资源测试已改为频率流程，新增原生六面包→四种资源接口→同频借用能源→真实Mek加压反应室出料，并检查闲置节点不抢货；覆盖私有权限、菜单会话、频率退出、当前版本六面／频率／核废料及物品的真实拆放、已移除节点拒绝与投影类型轮换／过期。四类投影shader已通过隐藏OpenGL着色、动态、淡出与遮挡验证；未启动游戏客户端。
