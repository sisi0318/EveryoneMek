# 人造微缩太阳 · alpha.25 基础版

已加入MekGravity，和原引力堆一起安装。依赖仍为Minecraft1.21.1、NeoForge21.1.241、Mekanism及Mekanism Generators10.7.19.85，不要求额外模组。

## 建造与点火

1. 放置**恒星约束器**。下面预留一层，左右各四格、后方八格、高度向上七格，组成9×9×9范围。
2. 左侧“结构与采能翼”窗口选择建造等级，查看预览／材料，再一键搭建。默认220块，材料不足可先搭已有部分，只扣成功放置的方块。停机后的“整组升级”用所选等级完整部件替换较低级的环、聚束器和采能翼，不降级更高级部件。需备齐本次升级材料；旧部件退回背包，满包则在玩家旁掉落。受保护位置拒绝时停止，保留已完成部分并恢复被拒绝部件。
3. 正面左侧**恒星燃料仓**放封装恒星燃料，也可用物品管道供料。
4. 正面右侧恒星能量接口为点火输入；背面两个、右侧两个为默认发电输出。
5. 向点火口供电，点击“点火”。默认首次消耗64 TFE，另保留2.048 TFE备用电，共需至少66.048 TFE。

仅首次点火付启动电费。普通启停、补货、保存/重载不再次付费。已有引力堆不受这台机器影响。

配置器潜行右键能量接口切换输入/输出：**红色＋为输入，蓝色－为输出**，切换后立即更新标识，拆下后物品保留模式。至少保留一个输入和一个输出。先放主控后，采能翼在对应位置自动朝内并拼接成面；旧结构中放歪的翼片也会自动校正。单独放置的翼片始终竖立，可用配置器水平转向。聚束器仍需用配置器瞄准恒星胚核。主控之外的结构部件可打开主界面，燃料仓打开本仓18格库存。

基础版使用固定220个部件位置；不能随意用新端口替换环、翼片、支撑或核心。完整位置见[九层图](art/solar-design/layout.svg)。一键搭建可保留已有高阶同类部件，只补缺失部件；同组混级翼片或聚束器错误朝向须先修正。

## 可选加工模块

[日冕加工舱](CORONAL_README.md)安装在采能翼外侧中心；每翼一台，旧太阳不必重建。批量熔炼／高温合金，9进9出，消耗共享储电并保留备用电。

## 恒星高温

已点火、启用且仍有可用燃料的完整太阳保持高温。**缓存满或红石暂停发电仍然危险**；主控停机、燃料耗尽、结构拆坏时熄火。历史点火记录不会让已停机的核心永久灼烧。

距离按生物身体与核心中心的最近距离计算，包括头部接触球面：

| 距离 | 提示与默认伤害 |
| --- | --- |
| 3～4格 | 黄色警告和短提示音，无直接伤害 |
| 2～3格 | 每秒2点灼伤，着火2秒 |
| 1.25～2格 | 每0.5秒4点灼伤，着火4秒 |
| 接触球面，0.45～1.25格 | 每0.25秒8点灼伤，着火6秒 |
| 最内核，≤0.45格 | 每次1,000,000点热伤，普通无防护生物接触即死 |

2点生命值为1颗心。胚核为可穿过的能量体，进入中心才触发致命档，最多0.25秒内判定；外层不会承受中心的百万伤害。进入更危险区域时立即升级警告，同一区域每2秒提醒一次，显示在快捷栏上方。警告沿用饰品的斜体红蓝错位叠影、轻微抖动效果，全文立即出现，金色／红色主字表示危险级别；正常淡出，其他行动栏信息保持原样。创造玩家可看到警告但不受灼伤，旁观者不触发；普通护甲、抗火和保命效果沿用正常伤害处理。手持盾牌不能隔绝周围热浪。高温作用于玩家和其他生物；熄火停止区域伤害，已经着火仍需正常灭火。

缓存满后，球体保持完整炽热外观和低速约束场；实际采能负载与高温分别同步。太阳配置新增 `stellarHeatEnabled` 与 `stellarHeatDamageMultiplier`，伤害倍率为0时保留预警。最内核基础伤害可由 `stellarCoreContactDamage` 调整，同样受全局灼伤倍率控制；仍走正常火焰伤害及保命流程。

## 燃料制备

1. 9个致密燃料丸合成1份**压缩恒星物质**。
2. 4份压缩恒星物质、4个反物质球和1张HDPE片合成**恒星燃料坯**。
3. 原Mek加压反应室：1个燃料坯 + 8,000 mB D-T化学品 + 1,000 mB水 → 1份**封装恒星燃料**。基础时长1,200tick，支持原机器升级。

太阳本体只接收成品燃料，不用一直供应气体。制备配方接入原Mek/JEI展示；另有“恒星燃料”分类显示反应预算。

一份燃料有737.28 PJ预算，机器只预装当前一份，不把整仓64份能量一次相加。背包和仓内仍是真实物品；已装入的剩余预算按实际反应保存。

## 发电与续航

| 全套等级 | 毛发电上限 | 净发电上限 | 单份满载时间 |
| --- | ---: | ---: | ---: |
| 初级 | 256 GFE/t | 243.2 GFE/t | 16小时 |
| 高级 | 512 GFE/t | 486.4 GFE/t | 8小时 |
| 精英 | 1.024 TFE/t | 972.8 GFE/t | 4小时 |
| 终极 | 2.048 TFE/t | 1.9456 TFE/t | 2小时 |

按默认2.5 J/FE、20 TPS、100%负载且持续用电计算。约束自耗5%，电满不烧料；降低负载会延长使用时间。

约束环和两个聚束器的最低等级决定反应上限；四组采能翼分别计算，每组贡献该等级功率的¼，再相加。每组9块需同级，四组之间允许不同级；侧栏显示左右前后翼的等级和采能/约束上限。

缓存1.024 PFE，每口额度1.024 TFE/t，默认四口共4.096 TFE/t。优先使用Mek的long能量能力；普通FE回退最多64次分批，单次int和接收设备仍会限制吞吐，不能保证所有线缆达到标称额度。自动弹出每tick轮换优先接口；能量窗口可逐个查看接口位置、模式与实际吞吐。外部管道主动抽取仍按调用顺序及各口额度处理。

## 自动运行与回收

- **充满再停**：启动后升至设定负载，持续充满实际缓存；只有最后一刻按剩余净空间精确补齐，满后停止耗料。有空间时恢复，不再以50%缓存为目标，也不在80%提前待机。
- **自动调载默认开**：出电后会根据实际送出的电量迅速恢复补能，受设定负载与设备等级限制。关闭时按正常升载速度恢复；两种模式都允许充满缓存，满后都不烧料。
- **自动续料默认开**：当前预算用尽才取下一份。关掉后不再自动投入新燃料，已投入部分仍可继续使用。
- **回收剩余燃料**：先停机，在“燃料与调载”窗口点击回收，背包需有空格。获得最大堆叠1的残余胶囊，可再次投入接着使用。胶囊不携带点火资格。
- 燃料仓可接比较器：当前预算和备用燃料均耗尽时输出15，其余为0。提前15分钟告警等高级阈值尚未加入。
- 主界面单独标明“核心高温／已熄火”，电满仍热时显示“高温待机”；显示仓内备用燃料份数，燃料窗口还列出其能量（超出计数范围显示下界“≥”，不溢出为负值）。主界面显示当前燃料在**设定负载**下的持续运行时间，避免瞬时降载导致续航数字暴涨；满缓存/停机显示暂停，不计算离线发电。

所有侧栏、回收和施工动作走服务端权限/距离校验；回收失败不会消耗预算。结构拆坏或区块卸载停工，旧接口失效，修好后恢复已保存资源。

## 模型和当前范围

上下约束环与冠架使用连续的八角细梁、转角和支柱接头，保留原220块布局。结构改动按位置即时通知主控，下一服务端tick更新拼接与成型状态，无需额外敲方块。恒星胚核的世界外观由独立shader绘制连续金橙对流、流动亮丝与略暗的球缘，取消球面上的像素方格。球体仍为1.25格半径，手持、物品栏、展示框和掉落物也使用同一表面shader；破坏粒子从shader导出16×16颜色贴图。物品发光仅为展示，不会在背包中触发高温伤害。采能翼保留分片弯曲采能面与中央观察孔。运行时球面自转，球外三层淡紫／冰蓝约束环独立旋转，亮弧沿环追逐；弯曲场线上有流动光点，上下聚束器向核心注入金白光束，四面采能翼持续接收能量流，球面保留暖色日珥。采能效果强度与转速跟随实际发电负载，缓存满时仍显示完整炽热球体和低速约束场，熄火才收束为冷态胚核。所有效果由客户端固定数量网格绘制，约束场使用专用shader绘制柔边和流动亮度，完整档每颗太阳430个特效四边形，简化档76个，不产生服务器粒子实体。聚束器伸出部分沿用真实选择框/碰撞。

[当前shader实渲染预览](art/solar-shader-preview.png)来自独立OpenGL环境，不是游戏截图。以下为alpha.13的静态模型资料：[恒星材质前后对比](art/photosphere-comparison.png)与[整机静态资源预览](art/solar-runtime-preview.png)来自游戏模型投影；[运行场特效的三个时刻](art/solar-field-preview.png)直接由运行时轨迹导出，均为离线预览，不是Minecraft截图。

alpha.23已加入[耀斑捕获、核心调谐与升载、引力物流及观测告警](ORBITAL_MODULES.md)，日冕加工、整组升级与客户端特效设置也已完成。CC遥测仍为候选，尚未接入。
