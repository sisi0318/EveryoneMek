# 人造微缩太阳 · alpha.8 基础版

已加入MekGravity，和原引力堆一起安装。依赖仍为Minecraft1.21.1、NeoForge21.1.241、Mekanism及Mekanism Generators10.7.19.85，不要求额外模组。

## 建造与点火

1. 放置**恒星约束器**。下面预留一层，左右各四格、后方八格、高度向上七格，组成9×9×9范围。
2. 左侧“结构与采能翼”窗口提供结构预览、材料提示与一键搭建。默认220块，生存实际扣料；保护区域、占用位置不会强行替换。
3. 正面左侧**恒星燃料仓**放封装恒星燃料，也可用物品管道供料。
4. 正面右侧恒星能量接口为点火输入；背面两个、右侧两个为默认发电输出。
5. 向点火口供电，点击“点火”。默认首次消耗64 TFE，另保留2.048 TFE备用电，共需至少66.048 TFE。

仅首次点火付启动电费。普通启停、补货、保存/重载不再次付费。已有引力堆不受这台机器影响。

配置器潜行右键能量接口切换输入/输出，至少保留一个输入和一个输出。聚束器、采能翼的朝向也可用配置器调整；应朝向反应腔。主控之外的结构部件可打开主界面，燃料仓打开本仓18格库存。

基础版使用固定220个部件位置；不能随意用新端口替换环、翼片、支撑或核心。完整位置见[九层图](art/solar-design/layout.svg)。一键搭建可保留已有高阶同类部件，只补缺失部件；混级翼片或错误朝向须先修正。

## 燃料制备

1. 9个致密燃料丸合成1份**压缩恒星物质**。
2. 4份压缩恒星物质、4个反物质球和1张HDPE片合成**恒星燃料坯**。
3. 原Mek加压反应室：1个燃料坯 + 8,000 mB D-T化学品 + 1,000 mB水 → 1份**封装恒星燃料**。基础时长1,200tick，支持原机器升级。

太阳本体只接收成品燃料，不用一直供应气体。制备配方接入原Mek/JEI展示；另有“恒星燃料”分类显示反应预算。

一份燃料有737.28 PJ预算，机器只预装当前一份，不把整仓64份能量一次相加。背包和仓内仍是真实物品；已装入的剩余预算按实际反应保存。

## 发电与续航

| 全套等级 | 毛发电上限 | 净发电上限 | 单份满载时间 |
| --- | ---: | ---: | ---: |
| 初级 | 256 GFE/t | 243.2 GFE/t | 16小时 |
| 高级 | 512 GFE/t | 486.4 GFE/t | 8小时 |
| 精英 | 1.024 TFE/t | 972.8 GFE/t | 4小时 |
| 终极 | 2.048 TFE/t | 1.9456 TFE/t | 2小时 |

按默认2.5 J/FE、20 TPS、100%负载且持续用电计算。约束自耗5%，电满不烧料；降低负载会延长使用时间。

约束环和两个聚束器的最低等级决定反应上限；四组采能翼分别计算，每组贡献该等级功率的¼，再相加。每组9块需同级，四组之间允许不同级；侧栏显示左右前后翼的等级和采能/约束上限。

缓存1.024 PFE，每口额度1.024 TFE/t，默认四口共4.096 TFE/t。优先使用Mek的long能量能力；普通FE回退最多64次分批，单次int和接收设备仍会限制吞吐，不能保证所有线缆达到标称额度。界面显示实际输出。

## 自动运行与回收

- **自动调载默认开**：低缓存积极补能，中段参考实际出电平滑调载，80%以上进入余辉待机，满缓存立即停耗料。原始25/80%可调阈值方案尚未做成自定义设置。
- **自动续料默认开**：当前预算用尽才取下一份。关掉后不再自动投入新燃料，已投入部分仍可继续使用。
- **回收剩余燃料**：先停机，在“燃料与调载”窗口点击回收，背包需有空格。获得最大堆叠1的残余胶囊，可再次投入接着使用。胶囊不携带点火资格。
- 燃料仓可接比较器：当前预算和备用燃料均耗尽时输出15，其余为0。提前15分钟告警等高级阈值尚未加入。
- 主界面直接显示当前预算按实际负载预计的时间；停机显示暂停，不计算离线发电。

所有侧栏、回收和施工动作走服务端权限/距离校验；回收失败不会消耗预算。结构拆坏或区块卸载停工，旧接口失效，修好后恢复已保存资源。

## 模型和当前范围

新增太阳像素表面、八角结构、分片弯曲采能面与中央观察孔。运行时太阳旋转、日冕与日珥起伏，能量光点向采能翼流动；待机缩小为余辉。所有效果由客户端固定数量网格绘制，不产生服务器粒子实体。聚束器伸出部分沿用真实选择框/碰撞。

[整机静态资源预览](art/solar-runtime-preview.png)来自游戏模型投影，不是Minecraft截图。

后续：耀斑升载、日冕加工仓、批量升级、CC遥测、可调告警阈值、更多模型动作和客户端特效设置。第一版不加入这些未完成功能的占位按钮。

## 配置与验证

太阳配置独立在每个世界的 `serverconfig/mekgravity-solar-server.toml`。能量值单位J，四级功率、点火/备用、缓存和端口额度可调；制备与燃料预算可由数据包修改。不会覆盖原引力堆配置。

构建及15项服务端GameTest通过，其中4项新增太阳测试覆盖两小时预算模拟、残余胶囊回收/重载、四翼混级、满缓存待机、损坏后能力失效、保护施工与材料扣除、远端打开主界面、真实能量立方接收，以及原加压反应室完成制备。两小时预算测试是144,000次稳态反应计算，不是等待两小时实时时钟。

未启动Minecraft客户端；模型、着色、窗面/曲面与GUI需要用户游戏内验收。客户端和服务端一起更新为alpha.8，mods内只保留一个MekGravity JAR。
